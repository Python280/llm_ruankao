# 操作系统定义、功能与层次结构

## 操作系统（OS，Operating System）

操作系统是管理计算机系统资源、控制程序运行、为用户提供接口的一组系统软件。

四大功能/角色：
- ☑ 管理系统的**硬件、软件、数据资源**
- ☑ **控制程序运行**
- ☑ **人机之间**的接口
- ☑ **应用软件与硬件之间**的接口

## 计算机系统层次结构

基于硬件之上的软件分为三层，自上而下：

```
┌────────────────────────────┐  ← 最终用户使用
│        a 应用软件          │  ← 应用软件开发人员
├────────────────────────────┤
│        b 系统软件          │  ← 系统软件开发人员
├────────────────────────────┤
│        c 操作系统          │  ← 系统软件开发人员
├────────────────────────────┤
│        计算机硬件          │
└────────────────────────────┘
```

> [!important] 层次记忆
> - **操作系统最靠近硬件**（c），向下管理硬件、向上支撑软件
> - 系统软件（编译、DBMS 等）在 OS 之上（b）
> - 应用软件在最上层（a），直接面向最终用户
> - ⚠ 真题"层次结构 a、b、c"答案 = **应用软件、系统软件、操作系统**（已核对讲义原图：最终用户/应用开发人员指向 a，系统软件开发人员指向 b 和 c）

> [!tip] 为什么 OS 在最底层软件层？
> OS 直接操作硬件（CPU 调度、内存分配、设备驱动），其它软件必须通过 OS 才能使用硬件——所以 OS 是"应用软件与硬件之间的接口"。
