# 性能指标与阿姆达尔定律

## 关键性能指标

- **主频 = 外频 × 倍频**
- 字长和数据通路宽度、主存容量和存取速度
- **CPI**（Clock cycle Per Instruction）：平均每条指令的时钟周期数
- **IPC**（Instruction Per Clock）：每周期运行指令条数，IPC = 1/CPI
- **MIPS**（Million Instructions Per Second）：百万条指令每秒
- **MFLOPS**：每秒百万个浮点操作
- 响应时间（RT）、完成时间（TAT）、兼容性

## 公式

$$MIPS = \frac{指令条数}{执行时间 \times 10^6} = \frac{主频}{CPI} = 主频 \times IPC$$

$$MFLOPS = \frac{浮点操作次数}{执行时间 \times 10^6}$$

> [!important] 真题（已算）
> 外频 200MHz、倍频 13 → 主频 = 200 × 13 = 2600MHz = **2.6GHz → 选 A**

## 阿姆达尔（Amdahl）定律

对某组件改进后，系统整体加速比：

$$R = \frac{T_p}{T_i} = \frac{1}{(1-F_e) + F_e / S_e}$$

- $F_e$：**改进比例**（可改进部分占总执行时间的比例，< 1）
- $S_e$：该部分的**加速倍数**（> 1）

> [!important] 真题（已算）
> 某功能占系统运行时间 60%，处理速度提高至 5 倍：
> R = 1 / ((1−0.6) + 0.6/5) = 1 / (0.4 + 0.12) = 1/0.52 ≈ **1.923 → 选 B**

> [!tip] 定律直觉
> 加速比受限于**不可改进部分** (1−Fe)。即使 Se→∞，R 最大 = 1/(1−Fe)。
> 例 Fe=0.6 时极限也只有 2.5 倍——"把 90% 时间之外的部分优化上天也没用"。

## 性能设计（瓶颈消除）

- 性能调整 = **查找和消除瓶颈**
- 数据库系统：CPU/内存使用、**优化数据库设计**、优化数据库管理、进程/线程状态、硬盘剩余空间、日志文件大小；真题空 = **查询语句性能**
- 应用系统：可用性、响应时间、**并发用户数**、特定应用资源占用
