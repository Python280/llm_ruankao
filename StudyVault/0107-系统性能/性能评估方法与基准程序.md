# 性能评估方法与基准程序

## 五种评估方法

| 方法                  | 描述                       | 特点             |
| ------------------- | ------------------------ | -------------- |
| 时钟频率法               | 以时钟频率高低衡量速度              | 仅考虑 CPU        |
| 指令执行速度法             | 单位 MIPS                  | 仅考虑 CPU        |
| 等效指令速度法（**吉普森混合法**） | 按各类指令在程序中所占比例 $W_i$ 加权计算 | 仅考虑 CPU，兼顾指令比例 |
| 数据处理速率法（**PDR**）    | PDR = L/R，值越大性能越好        | 考虑 CPU + 存储    |
| 综合理论性能法（**CTP**）    | 综合浮点/整数等                 | 更全面            |

## 评价程序精确度排名（高频）

$$\text{真实的程序} > \text{核心程序} > \text{小型基准程序} > \text{合成基准程序}$$

> [!important] 真题
> - 评测准确度**最高**的评价程序 = **真实程序**（选 A）
> - 用得最多、最频繁、作为标准基准测试程序 = **核心程序**（选 B）

## 常见基准程序

| 基准 | 测试重点 |
|---|---|
| **Dhrystone** | 综合性**整数**基准（编译器+CPU 整数/控制功能） |
| **Linpack** | **浮点**性能，高性能计算机排行（TOP500） |
| **Whetstone** | Fortran 综合性测试，以**浮点**运算为主 |
| **SPEC** | 速度测试 / 吞吐率测试 |
| **TPC** | **事务处理**（每秒事务数 TPC） |

TPC 系列：
- TPC-A：OLTP 环境下数据库和硬件性能
- TPC-B：不包括网络的纯事务处理
- TPC-C：联机订货系统（在线事务处理）
- TPC-D / TPC-H / TPC-R：决策支持（R 允许附加优化）
- TPC-E：大型企业信息服务系统
- TPC-W：基于 **Web** 应用的服务器测试标准

> [!tip] 记忆口诀
> - **D**hrystone = 整数（D 像"定"整数）；**W**hetstone/**L**inpack = 浮点
> - TPC 记"C 联机订货、H 决策支持、W Web"
