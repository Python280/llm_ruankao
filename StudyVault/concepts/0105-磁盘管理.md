### 错答笔记

**单缓冲顺序最长**
- Confusion: 等待时间用了完整旋转周期 30，正确为 30−3=27（处理 3ms 期间磁盘已朝下一记录方向转了 1 块=3ms，只需补 27ms 即可转回，不是等整圈 30ms）。曾误把"无等待"归到最后一块，实际无等待的是**第一块**（磁头初始就在 R0 起点）
- Key point: **每块结构 = [等待该记录转到磁头下方] + 读(3) + 处理(3)**。第一块磁头初始就位、等待=0 → 6ms；其余每块等待 = 旋转周期−处理时间 = 30−3=27ms（处理期间磁盘已转 1 块，补 9 块即可）→ 每块=27+3+3=33ms。10 个记录：6 + 9×33 = 6+297 = **303ms**。通式：等待 = 旋转周期 − 处理时间（处理时间 < 一块旋转时间时）
- 解题模板（参数可变，别死记答案）：每块读 = 周期/块数；第一块 = 读+处理（无等待）；其余每块 = (周期−处理)+读+处理；总计 = 第一块 + 其余×其余块数。例：周期30/10块/读3/处理6 → 第一块9、其余(24+3+6)=33×9=297、总计 9+297=306

**双缓冲计算**（统考真题题型；含单缓冲对照）
- 参数：T=读入缓冲区，M=送用户区，C=CPU处理
- 单缓冲每块 = max(T,C)+M，多块总式 = n×单块 + 最后C
- 双缓冲每块 = max(T,M+C)，多块总式 = n×单块 + 最后(M+C)
- 统考真题原参数（T=10,M=5,C=2,10块）：单缓冲 (10+5)×10+2=152μs；双缓冲 10×10+(5+2)=107μs
- ⚠ 网上有版本参数为 T=100/M=50/C=50（答案1550/1100）系博客改编讲解例，非真题原参数，以官方真题汇编为准
- 关键：单缓冲读T与送M互斥故M单独算；双缓冲读T与(M+C)并行故取max(T,M+C)

**统一流水线视角**（把缓冲区看成 2 段流水线）
- 总时间 = 首块全流程(T+M+C) + (n−1) × max(两条子流水线周期)
- 单缓冲切成 {T+M, C} 两线 → 瓶颈 max(T+M, C)
- 双缓冲切成 {T, M+C} 两线 → 瓶颈 max(T, M+C)
- 双缓冲视角 = 标准公式（完全等价无前提）；单缓冲视角在 T≥C 时与标准 max(T,C)+M 等价（都=T+M），软考真题参数均满足
- ⚠ 仅当 C>T+M（处理极慢成新瓶颈）时单缓冲两切法才分叉，回退到 max(T,C)+M；其余情况本视角永远对
- 本质：缓冲区 = 2 段流水线，首条走全流程、后续按瓶颈周期出，与流水线公式 T=nΔt+(k−1)Δt 同构
