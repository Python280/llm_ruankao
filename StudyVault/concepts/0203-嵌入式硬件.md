### 错答笔记

**嵌入式发展五阶段**
- Confusion: 答成 MCU→SCM→...，把开头 SCM 和 MCU 顺序弄反。正确是 SCM→MCU→SoC→Internet→智能云
- Key point: SCM（单片微型计算机，最早单片机时代）→MCU（微控制器，演进）→SoC（片上系统集成）→Internet（联网）→智能云。逻辑链"单机→控制→集成→联网→智能"
- ✅ 2026-08-13 专项重练答对（控制→系统集成 = MCU→SoC），🔴→🟢

### 英文词根与速记

**词根速查**：Micro=微 / Processor·Processing=处理器·处理 / Unit=单元 / Control=控制 / Digital=数字 / Signal=信号 / Graphics=图形 / System=系统 / Chip=芯片 / Single=单

**微处理器五家拆词**：
- MPU = Micro Processor Unit → 微处理器（板级通用核，ARM/MIPS/PowerPC）
- MCU = Micro Control Unit → 微控制器/单片机（单片化，外设全片内，8051）
- DSP = Digital Signal Processor → 数字信号处理器（哈佛+乘加，TMS320）
- GPU = Graphics Processing Unit → 图形处理器（万核并行，100 TFlops）
- SoC = System on Chip → 片上系统（一片全系统，软硬件无缝结合；⚠ 不是单纯处理器芯片）

**五家一句话**：MPU 板级 / MCU 单片 / DSP 信号 / GPU 画图 / SoC 全家桶

**五阶段顺序**：SCM（Single Chip Microcomputer 单片微型计算机）→ MCU（微控制器）→ SoC（片上系统）→ Internet（联网）→ 智能云
**逻辑链**：单机→控制→集成→联网→智能（从简单到复杂）
**为什么 SCM 在前**：SCM 的 M=Microcomputer（计算机），MCU 的 M=control（控制）；先有"单片机当计算机"（SCM），后演进成"控制器"（MCU），故 SCM 先、MCU 后
