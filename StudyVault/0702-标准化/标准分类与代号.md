## 一、标准的分类（p28）

### 1. 标准分级（讲义七级，逐字）

| 级别 | 讲义要点 |
|---|---|
| 国际标准 | ISO、IEC 等国际标准化组织 |
| 国家标准 | GB—中国、ANSI—美国、BS—英国、JIS—日本 |
| 区域标准 | 又称为地区标准：PASC—太平洋地区标准会议、CEN—欧洲标准委员会、ASAC—亚洲标准咨询委员会、ARSO—非洲地区标准化组织 |
| 行业标准 | GJB—中国军用标准、MIT-S—美国军用标准、IEEE—美国电气电子工程师协会 |
| 地方标准 | 国家的地方一级行政机构制订的标准 |
| 企业标准 | （讲义仅列级别） |
| 项目规范 | （讲义仅列级别） |

> [!warning] 讲义无"团体标准"一级
> 讲义 p28 口径为以上七级（含区域标准、项目规范），**未列团体标准**；无旁证，考试跟讲义。

### 2. 按约束性分类：强制 / 推荐 / 指导（p29）

讲义以我国国家标准代号给出三类（外加实物标准）：

| 性质 | 我国国家标准代号 | 记忆 |
|---|---|---|
| 强制性标准 | GB | 无后缀 |
| 推荐性标准 | GB/T | T＝"推"拼音首字母 |
| 指导性标准 | GB/Z | Z＝"指"拼音首字母 |
| 实物标准 | GSB | 单独代号，别与 GB 混 |

> [!tip] 一句话记忆
> "强制裸 GB，推荐 T（推），指导 Z（指），实物 GSB"。（拼音挂钩为自加口诀，代号本身以讲义为准。）

## 二、标准代号识别（p28-29）

### 1. 编号构成（p29）

- 国际、国外标准代号：**标准代号＋专业类号＋顺序号＋年代号**（四段顺序固定）。

### 2. 我国标准代号速查（p29）

| 标准级别 | 代号规则 | 讲义例 |
|---|---|---|
| 国家标准（强制） | GB | — |
| 国家标准（推荐） | GB/T | — |
| 国家标准（指导） | GB/Z | — |
| 国家标准（实物） | GSB | — |
| 行业标准 | 由**汉语拼音大写字母**组成 | 电子行业为 **SJ** |
| 地方标准 | **DB** 加上省级行政区划代码的**前两位** | 真题选项 DB11（讲义 p30） |
| 企业标准 | **Q** 加上企业代号 | — |

### 3. 国际与国外标准代号速查（p28）

| 代号 | 讲义口径 | 所属级别 |
|---|---|---|
| ISO、IEC | 国际标准化组织 | 国际标准 |
| GB | 中国国家标准 | 国家标准 |
| ANSI | 美国国家标准 | 国家标准 |
| BS | 英国国家标准 | 国家标准 |
| JIS | 日本国家标准 | 国家标准 |
| PASC | 太平洋地区标准会议 | 区域标准 |
| CEN | 欧洲标准委员会 | 区域标准 |
| ASAC | 亚洲标准咨询委员会 | 区域标准 |
| ARSO | 非洲地区标准化组织 | 区域标准 |
| GJB | 中国军用标准 | 行业标准 |
| MIT-S | 美国军用标准 | 行业标准 |
| IEEE | 美国电气电子工程师协会 | 行业标准 |

> [!tip] 机构全称助记（常识扩充，讲义原文仅"ISO、IEC 等国际标准化组织"）
> ISO＝国际标准化组织，IEC＝国际电工委员会；区域四大组织按地域记："太平洋 PASC、欧洲 CEN、亚洲 ASAC、非洲 ARSO"。

## 三、高频混淆

> [!warning] 判断题/选择题最爱
> - **四国代号张冠李戴**：GB—中国、ANSI—美国、BS—英国、JIS—日本，选项常互换。
> - **IEEE ≠ 国际标准**：IEEE 属**行业标准**级（讲义 p28 与 GJB、MIT-S 并列）；国际标准只认 ISO、IEC 等。
> - **GB/T 与 GB/Z 互换**：推荐＝T，指导＝Z。
> - **地方标准是 DB＋省级行政区划代码"前两位"**，不是完整代码。
> - 军用标准（GJB、MIT-S）属**行业标准**级，别误当国家/国际标准。
