# 索引文件结构（索引节点法）

## 结构

文件索引节点含 8 个地址项 iaddr[0]–iaddr[7]，每项 4 字节：
- iaddr[0]–iaddr[5]：**直接地址索引**（6 个）
- iaddr[6]：**一级间接**地址索引
- iaddr[7]：**二级间接**地址索引

磁盘索引块和数据块大小均为 1KB → 一个索引块含 1KB / 4B = **256 个地址**。

## 逻辑块号范围

```
直接：      0 ~ 5                  （6 块）
一级间接：  6 ~ 261                （256 块）
二级间接：  262 ~ 65797            （256×256 块）
```

**单个文件最大长度** = (6 + 256 + 256×256) × 1KB = **65798 KB**

> [!important] 真题（已算）
> 访问 icwutil.dll 的逻辑块号 0、260、518：
> - 0 → 直接地址索引
> - 260（≤261）→ **一级间接**
> - 518（>261）→ **二级间接**
> 第一空选 **A**；最大长度选 **D（65798 KB）**。

> [!tip] 计算通法
> 1. 每索引块地址数 = 块大小 / 地址项大小
> 2. 直接块数 = 直接地址项个数
> 3. 一级 = 256；二级 = 256²；逐级累加得范围与最大长度
> ⚠ 块号从 0 开始；边界值（261/262）是高频陷阱。

> [!warning] 易错点
> - 访问 k 级间接索引中的块需要**多次读盘**：二级间接 = 读一级索引块 + 读二级索引块 + 读数据块
> - 最大长度单位是 KB（块大小 1KB），别漏乘
