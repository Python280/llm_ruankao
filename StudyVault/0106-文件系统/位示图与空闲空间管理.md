# 位示图与空闲空间管理

## 空闲空间管理四方法

| 方法 | 说明 |
|---|---|
| 空闲区表法（空闲文件目录） | 为所有空闲区建表（起始号+长度） |
| 空闲链表法 | 空闲块/区链成链表 |
| 位示图法 | **1 bit 对应 1 个物理块**，0/1 表示空闲/占用 |
| 成组链接法 | Unix 采用，空闲块分组，组间链接 |

## 位示图大小计算

位示图位数 = 物理块总数；占用的**字数** = 物理块总数 / 字长。

> [!important] 真题（已算）
> 字长 32 位，磁盘容量 300GB，物理块 1MB：
> 块数 = 300GB / 1MB = 300 × 1024 = 307200
> 字数 = 307200 / 32 = **9600 字 → 选 D**

## 位示图定位

物理块号 b（从 0 起）：
- **字号 = b / 字长**（整除）
- **位号 = b % 字长**

例：1023 号物理块、字长 32 → 字号 = 1023/32 = **31**，位号 = 1023%32 = **31**。

> [!tip] 注意编号起点
> 字号/位号是否从 0 起要看题目约定；从 1 起则各 +1。

## 崩溃影响（真题）

> [!important] 真题
> 系统在将（　）文件修改的结果写回磁盘时发生崩溃，对系统的影响相对较大。
> A. 目录　B. 空闲块　C. 用户程序　D. 用户数据
> **答案 A（目录）**——目录记录文件的物理位置，损坏会导致文件找不到、文件系统结构破坏，影响面最大。
