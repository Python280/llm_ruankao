# 五类信息系统

★★★ **主考节**（讲义 p2 提要）。五类系统沿组织管理层次自下而上演进：**TPS → MIS → DSS**，ES 走知识智能路线，OAS 面向办公事务。考点集中在**组成部件、结构形式、问题类型**三件事上。

## 一、分类总览（讲义 p12）

| 系统 | 关键点 |
|---|---|
| 业务处理系统【TPS】 | 早期**最初级**的信息系统（20 世纪 50-60 年代）；功能：数据输入、数据处理（批处理、OLTP）、数据库维护、文件报表产生 |
| 管理信息系统【MIS】 | **高度集成化的人机信息系统**；**金字塔结构**，分多个层级 |
| 决策支持系统【DSS】 | 由**语言系统、知识系统和问题处理系统**组成；用于**辅助决策、支持决策** |
| 专家系统【ES】 | **知识＋推理＝专家系统**；人工智能的一个重要分支 |
| 办公自动化系统【OAS】 | 由**计算机设备、办公设备、数据通信及网络设备、软件系统**组成 |
| 企业资源计划【ERP】 | 打通供应链，集成、整合（属 0505 企业信息化主题，此处仅知其在分类表内） |

> [!note] 32h 的分法（六类）
> 32h 将信息系统分为 **6 类**：业务（数据）处理系统、管理信息系统、决策支持系统、专家系统、办公自动化系统、**综合性信息系统**——比讲义表多一个"综合性信息系统"兜底类。（32h 第4小时 印刷p29）

## 二、TPS 业务处理系统（讲义 p13）

**业务处理系统（Transaction Processing System, TPS）**又可称为**电子数据处理系统（Electronic Data Processing System, EDPS）**，是计算机在管理方面早期应用的**最初级形式**的信息系统。

- TPS 服务于组织管理层次中**最低层、最基础**的信息系统；它既是信息系统发展的最初级形式，也是**基础和桥梁**，因简单成熟常用**结构化生命周期法**开发。
- 对事务所发生的数据进行**输入、处理和输出（IPO）**。
- **五大功能**（讲义 p13 结构图）：

| 功能 | 说明 |
|---|---|
| **数据输入** | 原始业务数据的采集录入 |
| **数据处理** | 两种处理方式：**批处理**、**联机实时处理（OLTP）** |
| **数据库维护** | 与数据处理双向交互，保持数据更新 |
| **文件、报表生成** | 打印终端输出文件与报表 |
| **查询处理** | 与数据处理双向交互，响应即时查询 |

> [!tip] 记忆
> TPS 五功能："**输、处、库、报、查**"；处理方式二选一："**批处理 or 联机实时**"。

## 三、MIS 管理信息系统（讲义 p14-15）

**管理信息系统（Manage Information System, MIS）**是由业务处理系统发展而成的，是在 **TPS 基础上引进大量管理方法**对企业整体信息进行处理，并利用信息进行**预测、控制、计划**、辅助企业全面管理的信息系统。MIS 是一个**高度集成化的人机信息系统**，是企业信息系统中职能明确、体系结构稳定、处理技术成熟、应用最成功的分支。

### 四大部件

**信息源、信息处理器、信息用户、信息管理者**。

### 开环结构 vs 闭环结构

| | 开环结构 | 闭环结构 |
|---|---|---|
| 决策过程中 | **不收集**外部信息，不根据信息改变决策，直至产生本次决策结果 | **不断收集信息、不断发送给决策者、不断调整决策** |
| 事后评价 | 供**以后**的决策作参考 | 最后执行的决策已不是当初设想的决策 |
| 典型系统 | **批处理系统**属于开环系统 | **计算机实时处理系统**属于闭环系统 |

> [!warning] 易错（讲义 p15 原话）
> **批处理＝开环，实时处理＝闭环**。例外：对一些**较长的决策过程**，批处理系统也能构成闭环系统。

### 金字塔结构与功能/层次矩阵

按处理内容及决策层次，MIS 是**金字塔式结构**：

- **层次（行）**：战略计划 → 管理控制 → 运行控制 → 业务处理；**下层处理量大，上层处理量小**。
- **功能（列）**：销售与市场、生产、后勤（供运）、人事、财务与会计、信息处理、高层管理。
- 行列交叉 = 每一种**功能子系统**，整体构成功能/层次矩阵。

三种综合方式：

| 综合方式 | 划分依据 |
|---|---|
| **横向综合** | 按**层**划分子系统 |
| **纵向综合** | 按**条（职能）**划分子系统，如把车间、科室、总经理层的所有人事问题划成一个子系统 |
| **纵横综合** | 金字塔中任何部分均可与其他任意部分组成子系统，随意组合自如使用 |

### 七子系统（职能）

| 子系统 | 要点 |
|---|---|
| **销售市场** | 销售与推销；运行控制含销售人员雇用训练、日常调度；战略计划含新市场开发战略 |
| **生产** | 产品设计、生产设备计划/调度/运行、质量控制；典型业务：生产订货、装配订货、成品票、废品票、工时票 |
| **后勤** | 采购、收货、库存控制、分发；战略分析含"做或买"战略 |
| **人事** | 雇用、培训、考核记录、工资、解雇 |
| **财务与会计** | 财务目标＝保证财务要求且花费最低；会计＝分类总结、标准财务报告、预算与成本分析 |
| **信息处理** | 保证企业信息需要；办公自动化可算独立或合一的子系统 |
| **高层管理** | 为最高领导层服务：查询信息、支持决策、编写文件、发送指令；战略计划关心公司方向与资源计划 |

> [!note] 功能-过程结构
> 子系统名称标注的是**管理功能或职称，而不是计算机名词**；职能的完成往往通过"**过程**"（逻辑上相关活动的集合）实现，故 MIS 功能结构常表示为**功能-过程结构**。

> [!tip] 来源：官方 §3.3 印刷p119-123（四大部件、功能/层次矩阵、七子系统细节）；32h 第4小时 印刷p31（七子系统清单、"上层是子系统和功能，底层是各个过程"）

## 四、DSS 决策支持系统（讲义 p16）

**决策支持系统（Decision Support System, DSS）**是一个由**语言系统、知识系统和问题处理系统** 3 个互相关联的部分组成的、基于计算机的系统。

### 定义一的四特征（讲义 p16，必背）

1. **数据和模型**是 DSS 的主要资源
2. DSS 用来**支援**用户作决策而**不是代替**用户作决策
3. DSS 主要用于解决**半结构化及非结构化问题**
4. DSS 的作用在于提高决策的**有效性**而不是提高决策的**效率**

### 发展脉络

| 时间 | 形态 |
|---|---|
| 20 世纪 70 年代中期 | 首次提出 DSS 一词 |
| 70 年代末期 | 由**模型库、数据库、人机交互系统** 3 个部件组成 |
| 80 年代初 | 增加**知识库与方法库**，构成**三库系统或四库系统** |
| 80 年代后期 | 人工智能 + DSS = **智能决策支持系统（IDSS）**，提高支持非结构化决策问题的能力 |
| 近年 | DSS + 计算机网络 = **群体决策支持系统（GDSS）**；再集成分布式数据库/模型库/知识库 = **分布式决策支持系统（DDSS）** |

### 两库结构（基本结构之一）

DSS 的两种基本结构形式：**两库结构**和**基于知识的结构**。两库结构由**数据库子系统、模型库子系统和对话子系统**形成**三角形分布**的结构。

### 九大功能

| # | 功能 |
|---|---|
| 1 | 整理和提供本系统与决策问题有关的各种**数据**（生产/库存/财务/设备运行数据） |
| 2 | 收集、存储并及时提供决策有关的**外部信息**（市场需求、商品价格、原材料供应、竞争对手状况） |
| 3 | 及时收集和提供各项活动的**反馈信息**（计划完成情况、产品销售情况、用户反映） |
| 4 | 对各种决策**模型**的存储和管理（库存控制、生产调度、投入产出模型） |
| 5 | 对常用**数学、统计、运筹方法**的存储和管理（统计检验、回归分析、线性规划） |
| 6 | 对数据、模型、方法的**有效管理**（查找、变更、增加、删除） |
| 7 | 运用模型和方法对数据**加工**，得出支持决策的信息（汇总、分析、预测） |
| 8 | **人-机对话接口和图形加工、输出**功能（回答 "What…if…" 类问题，输出统计图表） |
| 9 | 支持**分布使用方式**，提供有效传输功能（异地共享数据、模型、方法） |

### 五特点

1. **面向决策者**：收集、存储、输出的一切信息都为决策者服务
2. **支持对半结构化问题的决策**（传统 EDPS/MIS 难以解决）
3. 作用是**辅助、支持**决策者：不可能取代人做出决策，**不应提供答案**，也不应强加预先规定的决策顺序
4. 体现决策过程的**动态性**：动态确定问题解答，并在运行中完善调整系统
5. 提倡**交互式处理**：将决策人的经验、观念、判断与客观信息相结合

### 组成补充：数据仓库与建模

- 事务处理系统的数据须经**重组和确认**才对决策支持有效 → 通过**数据仓库**解决；数据仓库是**与作业层系统分离存在**的数据库。
- **数据挖掘**工具称为**智能体**；挖掘结果四类：**联合**（联系各事件）、**定序**（识别模式次序）、**分类**（按模式组织数据）、**聚类**（推导小组区分规则）。
- 建模四法：**穷枚举法**（常由神经网络支持）、**算法**、**启发式**（经验法则，常用于专家系统设计）、**模拟**（仿真，用于策略改变分析）。
- **组建过程**（32h 五步）：**数据重组 → 建立数据仓库 → 建立数据字典 → 数据挖掘 → 建立模型**。

> [!tip] 来源：官方 §3.4 印刷p124-129（发展脉络、两库结构、九功能、五特点、数据仓库/建模）；32h 第4小时 印刷p31（两定义、九功能概括、组建五步）

## 五、ES 专家系统（讲义 p17-18）

**专家系统（Expert System, ES）**是一个**智能计算机程序系统**，其内部含有某个领域具有专家水平的大量知识与经验，能够利用人类专家的知识和解决问题的方法来处理该领域的问题。ES 是**人工智能的一个重要分支**。

核心公式（对照记）：

| 专家系统 | 传统软件 |
|---|---|
| **知识＋推理＝系统** | 数据结构＋算法＝程序 |

设计以**知识库和推理机**为中心展开。

### ES vs 一般计算机系统（讲义 p17 表）

| 系统 | 专家系统 | 一般计算机系统 |
|---|---|---|
| 功能 | **解决问题、解释结果、进行判断与决策** | 解决问题 |
| 处理能力 | **处理数字与符号** | 处理数字 |
| 处理问题种类 | 多属**准结构性或非结构性**，可处理**不确定的知识**，使用于**特定的领域** | 多属结构性，处理确定的知识 |

### 六组成（讲义 p18 + 官方 §3.5.3，必背）

| 组成 | 要点 |
|---|---|
| **知识库** | 存储求解实际问题的**领域知识**；知识分两类：**事实性知识**与**启发性知识**；一次推理中内容不变 → 又称**静态知识库** |
| **综合数据库** | 存储问题**初始状态描述、中间结果、求解过程记录**等；运行中不断变化 → 又叫**动态知识库**（工作存储器）；与知识库一起构成完整知识库 |
| **推理机** | 实质是**规则解释器**（又称控制结构）；与知识库一起构成**专家系统核心**；一般使知识库与推理机**相分离**以保证模块性、灵活性、可维护性 |
| **知识获取** | 两方面功能：**知识的编辑求精**＋**知识自学习**；维护知识库的一致性和完整性 |
| **解释程序** | **面向用户服务**，解答用户各种问题；实现方法多为按推理顺序连接各步数据知识，解释时逐步显示**推理链** |
| **人-机接口** | 两部分：**与用户的接口**（咨询、建议）＋**与领域专家和知识工程师的接口**；完成内部表示与外部表示的相互转换 |

### 三种推理方式

| 推理方式 | 别名 | 策略 | 适用 |
|---|---|---|---|
| **正向推理** | 前向推理 | **数据驱动**：从条件出发推出结论 | 目标**解空间很大**的问题 |
| **反向推理** | 逆向推理 | **目标驱动**：先假设结论正确，再验证条件 | **解空间较小**的问题 |
| **双向推理** | 混合推理 | 正反向同时进行，达到一致状态获得解 | 常用正向定假设次序、反向验证假设 |

### 三要素与三级知识

ES 由三要素组成：**综合数据库、知识库、推理机**，分别对应**数据级、知识库级、控制级**三级知识；传统应用程序只有数据和程序两级结构。

### ES 六特性

1. **超越时间限制**：开发完成后可 24 小时持续运作
2. **操作成本低廉**：日常操作成本比人类专家便宜许多
3. **易于传递与复制**：知识可轻易传递或复制
4. **处理手段一致**：对所处理问题具有一致性输出
5. **善于克服难题**：适合费时、复杂度高、重复性高的工作
6. **适用特定领域**：通常只使用小范围的特定知识领域

> [!warning] 易错
> ① **综合数据库 = 动态**知识库，**知识库 = 静态**知识库，别记反。② 推理机实质是**规则解释器**；"解释程序"才是面向用户答疑的，两个"解释"不同物。③ ES 模拟的是**人类专家在问题领域的推理**，而不是模拟问题领域本身（传统程序才模拟问题领域）。

> [!tip] 来源：官方 §3.5 印刷p129-133（六组成细节、三要素三级、六特性、五不同点）

## 六、OAS 办公自动化系统

与 TPS/MIS 等以**数据处理**为主的信息系统不同，OAS 解决的是包括**数据、文字、声音、图像**等信息的**一体化处理**问题。

### 概念与四大支柱

办公自动化就是**办公信息处理手段的自动化**；以先进科学技术为基础，集**文字、数据、语言、图像**为一体的综合性、跨学科的人机信息处理系统。四大支柱：**计算机技术、通信技术、系统科学、行为科学**——其中以**行为科学为主导，系统科学为理论基础**。

### 办公活动三组常识

| 组 | 内容 |
|---|---|
| 5 种信息类型 | 数据（数值型为主）、文字、声音、**图形（静态）**、**图像（动态）** |
| 4 类人员 | 主管人员（领导）、专业人员、秘书、办事员 |
| 5 项工作 | 处理数据、文字处理、分类归档、沟通、决策；**越底层承担前几项越多，高层集中在沟通与决策** |

### 三大功能（按业务性质）

| 功能 | 系统名称 | 要点 |
|---|---|---|
| **事务处理** | 事务办公系统 | 分**单机**（文字处理、日程安排、文档管理、电子报表、数据处理）与**多机**（电子会议、电子邮件、语音处理、图形图像处理、联机情报检索） |
| **信息管理** | 管理型办公系统 | 对信息流收集、加工、传递、存取、分析、反馈；**分布式处理系统**，具通信和网络功能 |
| **辅助决策** | 决策型办公系统 | 以经理型办公系统提供的信息为基础，建立决策模型自动产生较符合实际的决策方案 |

### 四组成（讲义 p12 表）

**计算机设备**（主机系统、终端设备、外部设备）、**办公设备**（电话、传真、复印机、轻印刷设备等）、**数据通信及网络设备**、**软件系统**（系统软件、专用软件、支持软件）。

> [!tip] 来源：官方 §3.6 印刷p133-136（四大支柱、三组常识、三功能、四组成；讲义仅列四组成）；32h 第4小时 印刷p32（一体化处理、三功能、四组成）

## 七、五类系统对比总表

| 系统 | 名称 | 定位/服务层次 | 核心组成 | 处理问题 | 题眼 |
|---|---|---|---|---|---|
| **TPS** | 业务处理系统 | 最低层、最基础（50-60 年代最初级） | 五功能：输、处、库、报、查 | 结构化日常业务 | 又称 EDPS；批处理/OLTP |
| **MIS** | 管理信息系统 | 企业整体、全面管理 | 四部件；金字塔/七子系统 | 结构化 | 开环=批处理，闭环=实时 |
| **DSS** | 决策支持系统 | 中高层决策 | 语言/知识/问题处理；两库结构 | **半结构化及非结构化** | **支持不代替**；有效性≠效率 |
| **ES** | 专家系统 | 特定领域专家级 | 六组成（知识库+推理机为核心） | 半/非结构化、不确定知识 | 知识+推理=系统 |
| **OAS** | 办公自动化系统 | 办公事务全员 | 四组成 | 数据/文字/声音/图像一体化 | 四支柱，行为科学主导 |

> [!tip] 总口诀
> "**业管决专办**"（TPS/MIS/DSS/ES/OAS）演进线；每类一句话：**TPS 五功能打地基，MIS 金字塔管全局，DSS 两库辅半非，ES 知识加推理，OAS 四支柱办公文**。
