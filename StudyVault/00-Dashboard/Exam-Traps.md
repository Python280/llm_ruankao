# Exam Traps · 易错点

> 每条 → 概念笔记。考前 10 分钟只刷本页。

## 计算机组成

> [!warning] RISC 陷阱 → [[冯诺依曼与指令系统-CISC-RISC]]
> "寻址方式丰富、指令功能强"是 **CISC**！问"RISC 不包括"就选它。

> [!warning] 分级存储目的 → [[CPU与局部性原理-分级存储]]
> 答"**容量、价格、速度**三者矛盾"，不是"主存容量不足"。

> [!warning] DMA 通路 → [[IO控制方式]]
> 在**主存与外设**之间，不经 CPU。选项常设"CPU 与外设"诱导。

## 操作系统

> [!warning] 层次 a/b/c → [[操作系统定义功能层次结构]]
> 自上而下 = **应用、系统软件、操作系统**（OS 最贴硬件）。方向别反。

> [!warning] 批处理无交互 → [[操作系统分类]]
> 交互性是**分时**的标志；实时重**可靠+限时**。

## 进程管理（重灾区）

> [!warning] 线程栈私有 → [[进程线程PCB三态]]
> 同进程线程**共享打开文件**，**不共享栈指针**。

> [!warning] 阻塞不能→运行 → [[进程线程PCB三态]]
> 阻塞事件发生后必须**先就绪**再经调度运行。

> [!warning] S 为负含义 → [[同步互斥与PV操作]]
> S=−2 = 无可用资源且 **2 个进程排队**。V 操作不会阻塞。

> [!warning] 前趋方向 → [[前趋图]]
> 记 **(前驱,后继)**；选项常用反方向集合做干扰（真题选 C 而非 A/D）。

> [!warning] 死锁资源数 → [[死锁与银行家算法]]
> n(m−1)+1，是"每个进程差 1 个"的最坏情况 +1，别用 n×m。

> [!warning] 银行家先看 Available → [[死锁与银行家算法]]
> 分配后必须**能找到安全序列**才安全；逐个试，别想当然。

## 存储管理

> [!warning] 页号高位 → [[页式存储]]
> 5148H：页号 = 高 4 位(5)，页内 = 低 12 位(148H) 不变；物理地址只换高位。

> [!warning] 越界比较对象 → [[段式与段页式存储]]
> 段内偏移和**段长**比，不是和基地址比。(0,810) 越界因 810>800。

> [!warning] 碎片类型 → [[页式存储]]
> 页式 = 内部碎片；段式 = 外部碎片。

## 磁盘

> [!warning] 寻道别漏乘 → [[磁盘存取时间与旋转优化]]
> 寻道 = 磁道数×每磁道时间；100 块题 = 202×100 = **20200（D）**，不是 11200。

> [!warning] 旋转优化两个时间 → [[磁盘存取时间与旋转优化]]
> 顺序存放 366ms vs 优化 66ms；"处理 3ms 转 1 块"是节奏关键。

## 文件系统

> [!warning] 间接边界 → [[索引文件结构]]
> 直接 0–5；一级 6–261；二级 262+。260 是**一级**不是二级！

> [!warning] 崩溃最大影响 → [[位示图与空闲空间管理]]
> **目录**文件损坏影响最大（文件不可达）。

## 性能

> [!warning] 阿姆达尔代入 → [[性能指标MIPS与阿姆达尔定律]]
> Fe 是**可改进部分占比**；0.6 提速 5 倍 → 1.923，别算成 1+0.6×4。

> [!warning] 精确度排名 → [[性能评估方法与基准程序]]
> 最高 = **真实程序**；用得最多 = **核心程序**。两空别混。

## 嵌入式系统（第二章）

> [!warning] 初始化顺序 → [[嵌入式系统概念与架构]]
> **片级→板级→系统级**。选项爱反着写。

> [!warning] HAL 在哪层 → [[嵌入式系统概念与架构]]
> 硬件抽象层 HAL 与 BSP 在**抽象层**，不在操作系统层（32h 真题考"错误叙述"）。

> [!warning] 存取速度最快 → [[嵌入式微处理器分类]]
> **寄存器组** > Cache > 内存 > Flash。别顺手选 Cache。

> [!warning] SoC 双重身份 → [[嵌入式微处理器分类]]
> 既是**产品**（集成电路）又是**技术**（设计过程）。说"只是处理器芯片"错。

> [!warning] AI 芯片特征干扰项 → [[AI芯片]]
> 六特征无"**信号/图像处理能力**"——那是 GPU 的活，选项爱塞进来（真题选 B 组）。

> [!warning] 串行总线三性 → [[处理器体系结构与总线]]
> 按位传、**波特率可调**、正确性靠**校验码**。"波特率不可变/全双工/软件查询"皆错。并行=短距、串行=长距，别反。

> [!warning] RTOS 特点无"通用性" → [[嵌入式实时操作系统]]
> 五特点 = 微型化/代码质量高/专业化/实时性强/可裁减可配置。**通用性**是干扰项。

> [!warning] EDF 头端 vs 最晚末端 → [[嵌入式实时操作系统]]
> 最早截止期 EDF = 截止时间**头端**定优先级；最晚 = **末端**。"接近截止期调到最高"= EDF（真题选 D）。

> [!warning] 微内核性能低 → [[内核架构与鸿蒙]]
> "微内核功能代码互相调用、性能很高"错——频繁**用户/内核态切换**，性能**低于**宏内核。

> [!warning] 鸿蒙 = 微内核 → [[内核架构与鸿蒙]]
> 说"鸿蒙内核层采用**宏内核**"错（真题选 B）。四层自下而上：内核层→系统服务层→框架层→应用层。

> [!warning] NDB vs FDB 张冠李戴 → [[嵌入式数据库分类与特点]]
> "以**文件方式**存磁盘"是 **FDB**！NDB = 4G/5G + 客户端/通信协议/远程服务器（真题选 D）。

## 计算机网络（第三章）

> [!warning] 根服务器迭代才对 → [[DHCP与DNS]]
> 真题"不合理的是"：根域名服务器采用**递归**（应迭代）。递归加重上一级负担。

> [!warning] 反解要 PTR → [[DHCP与DNS]]
> nslookup 查 IP 得、查名不得 → **创建 PTR 记录**，不是清/刷缓存、不是重启。

> [!warning] Linux DNS 配置 → [[DHCP与DNS]]
> **/etc/resolv.conf**（nameserver/domain/search/sortlist）。/etc/hostname 是主机名。

> [!warning] 备用路径默认不干活 → [[网络冗余设计与布线]]
> 备用路径**仅主路径失效时启用**；"同时投入使用分担流量"是**负载分担**（真题选 B 错项）。

> [!warning] UDP 不可靠 → [[IP-TCP-UDP]]
> DHCP/DNS 走 **UDP = 不可靠**；FTP/HTTP 走 TCP 可靠。问"可靠传输"别选 UDP 系。

> [!warning] 云服务层次 → [[网络指标与5G云计算]]
> 给用户 = **SaaS**；给开发者 = **PaaS**；给基础设施 = **IaaS**。三层顺序别颠倒。

## 数据库（第四章）

> [!warning] 自然连接去重列 → [[关系代数运算]]
> 自然连接**自动去除公共属性列**；等值连接不去。算结果列数时 3+2−1 别按笛卡尔积 3+2。

> [!warning] 除运算方向 → [[关系代数运算]]
> R÷S 是"象集**包含** S 投影"的 R 侧属性；问"查所有/全部"才用除，方向别反。

> [!warning] 3NF vs BCNF → [[函数依赖与范式]]
> BCNF 要求**每个函数依赖的决定因素都含码**；3NF 只禁非主属性传递依赖。STJ 是 3NF 非 BCNF 经典例。

> [!warning] Redo/Undo 别反 → [[安全完整性并发与恢复]]
> **已提交 Redo、未提交 Undo**。介质故障用备份+日志重做已提交事务。

> [!warning] 视图 vs 物化视图 → [[案例解题方法]]
> 视图是虚表（不存数据）；**物化视图**才存数据需刷新。案例爱考"提高查询性能"选物化。

> [!warning] 分布式透明性层次 → [[数据库体系结构与设计阶段]]
> 分片透明 > 位置透明 > 局部映射透明，**最高是分片透明**（用户不知分了片）。

## 系统工程与信息系统（第五章）

> [!warning] DSS 两库 → [[五类信息系统]]
> DSS 基本结构 = **数据库 + 模型库**（两库结构）；基于知识 = 加知识库。别与 ES 组成混。

> [!warning] ES 推理机 vs 知识获取 → [[五类信息系统]]
> **推理机**用知识库推理求解；**知识获取**负责把专家知识装入知识库（输入口）。角色别反。

> [!warning] BSP 方向 → [[企业信息化与战略规划]]
> BSP = **自上而下规划、自下而上实现**。选项爱写成同向。

> [!warning] 电子政务主体 → [[电子政务]]
> 政府对**企业** = G2B（采购/营商）；政府对**公民** = G2C（社保/服务）。企业向政府报税 = B2G。

> [!warning] 诺兰六阶段 → [[生命周期与开发方法]]
> 初始→蔓延→控制→集成→数据管理→成熟，**控制→集成**是转折（从设备管理转向数据管理）。
