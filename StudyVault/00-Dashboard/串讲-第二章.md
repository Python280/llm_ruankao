# 串讲 · 第二章 嵌入式技术（9 分）

> 一条线搭起一台嵌入式设备：**是什么 → 怎么开发 → 用什么硬件 → 跑什么系统 → 存什么数据**。

## 0201 概述：嵌入式是什么

**定义三要素**：以**应用**为中心、以**计算机技术**为基础、可配置可裁剪的**专用**计算机系统（不是通用 PC）。
> 口诀：**应中心、计基础、专用可裁剪**。软考爱把"中心/基础"说反挖坑。

**五部分组成**：嵌入式处理器 + 支撑硬件 + 嵌入式 OS + 支撑软件 + 应用软件。

**五层架构**（自上而下）：应用 → 中间件 → 操作系统 → 抽象层 → 硬件。口诀"**应中操抽硬**"。
- 抽象层 = HAL + BSP（HAL 给 OS 虚拟硬件可移植，BSP 板级驱动帮 OS 管硬件）
- 中间件 = 连接两个独立应用的桥梁（DDS/CORBA/Hadoop/DB）
- ⚠ 任务调度属 OS，不属 HAL

**初始化三级**（BootLoader 加电）：**片级→板级→系统级**，不可颠倒。
- 片级：CPU 自己（纯硬件）；板级：其他设备（软硬兼有）；系统级：OS 从 Flash 搬内存、跳转内核
- 类比：CPU 醒(片)→设备就位(板)→请 OS 进场(系)

**看门狗**：定时器溢出→中断/复位（防死锁，超时不喂狗就重启）。**JTAG**：IEEE 1149.1，CPU 调试接口。

## 0202 设计：怎么开发

**开发模式**：宿主机(PC)+目标机(嵌入式)。宿主机开发，目标机运行。
**交叉编译**：宿主机编译→目标机运行。根本原因=**可行性**（目标机资源紧缺无法运行编译工具），非速度。
> 类比：目标机太小装不下编译器，借宿主机大厨房做好饭端过去。

**交叉开发 7 工具**（3 类）：
- 编译链接 2：交叉编译器、交叉链接器
- 装载 2：动态装载器、链接装载器
- 调试 3：调试器、调试监视器、调试代理
> ⚠ 跨类混拼（调试编译器/链接监视器）都是假词。

**宿主↔目标连接**：串口、网络、JTAG。

**低功耗 5 方面**（软件层）：软硬件协同 / 编译优化 / 减运行时间(算法) / **中断代查询** / 电源管理。
> ⚠ 干扰三件套"代码优化/环境优化/仿真实验"。中断代查询=查询 CPU 持续轮询耗电，中断 CPU 可休眠省电。

## 0203 硬件：用什么处理器

**发展五阶段**：SCM(单片微型计算机)→MCU(微控制器)→SoC(片上系统)→Internet→智能云。
> 逻辑链：单机→控制→集成→联网→智能。SCM 在前(计算机)、MCU 在后(控制器)。

**微处理器五家**：
- MPU=板级通用核（ARM/MIPS/PowerPC，32 位以上高性能）
- MCU=单片化（外设全片内，控制主流，8051）
- DSP=哈佛+乘加（信号处理快 10-50 倍，TMS320）
- GPU=万核并行（100 TFlops，图形+AI）
- SoC=一片全系统（软硬件无缝结合，⚠不是单纯处理器芯片）
> 口诀：MPU 板级 / MCU 单片 / DSP 信号 / GPU 画图 / SoC 全家桶。

**AI 芯片四类**（技术架构）：GPU、FPGA、ASIC、类脑芯片（题问"三种"答 GPU/FPGA/ASIC）。
**六特征**：范式、训推、大数据、低精度、可重构、工具链（干扰项：信号处理/图像处理/可定制）。

**冯诺依曼 vs 哈佛**：
- 冯（普林斯顿）：指令数据合并存储、共享总线、PC 用(I3/I5/I7)
- 哈佛：分离存储、4 总线、并行读取、DSP/嵌入式用
> ⚠ 高频陷阱说反（PC=冯，DSP=哈佛）。

**总线**：分时共享、半双工；并行=短距离，串行=长距离；串行波特率可调、正确性靠校验码。

## 0204 OS：跑什么系统

**RTOS 五特点**：微型化/代码质量高/专业化/实时性强/可裁减可配置。口诀"微高专实裁"。
> ⚠ "通用性"是干扰项（与专业化相反）。

**实时三指标**（越小越好）：中断响应延迟/任务切换时间/信号量混洗时间。口诀"中断-切换-混洗"。
> ⚠ 指令流水线是 CPU 概念不是 RTOS 指标。

**调度四算法**：优先级(固定)/抢占式(按紧急，大多数 RTOS)/EDF 最早截止期(头端)/最晚截止期(末端)。

**宏内核 vs 微内核**：
- 宏："全塞内核里，快但脆"——效率高但庞大难剪裁、稳定性安全性差
- 微："内核只留调度+IPC，稳但慢"——结构清晰/可剪裁/可靠/可分布式，但频繁切换性能低
> **鸿蒙=微内核**。

**鸿蒙四层**（自下而上）：内核层→系统服务层→框架层→应用层。
**鸿蒙四特性**：分布式架构/确定时延+IPC 提 5 倍/微内核安全/统一 IDE 多端部署。

## 0205 数据库：存什么数据

**本质**：嵌入应用进程，零配置轻量级。与服务器最大区别=**运行地址空间**（服务器独立守护进程 TCP/IP，嵌入式同进程 API）。代表 SQLite/BerkeleyDB（嵌入式）vs Oracle/MySQL/SQLServer（服务器）。

**四特点**：嵌入式(基本特性)/实时性/移动性/伸缩性。口诀"嵌实移伸"。
> 蕴含：**嵌入⇒移动**（官方原话"一定"）、**嵌入⇏实时**（需额外工作）。基本特性是嵌入性（不是实时性）。

**三类**（按存储位置）：
- MMDB(内存)：主拷贝常驻内存，事务不访问 I/O，支持实时事务**最佳**
- FDB(文件)：被动访问，了解格式任何程序可读→**安全性低**
- NDB(网络)：远程映射本地，**无需解析 SQL**，客户端小无须可剪裁；三组成=客户端/通信协议/远程服务器

## 串联：一台嵌入式设备怎么搭起来

1. **定调**（0201）：嵌入式=专用计算机，五层架构(应中操抽硬)，HAL+BSP 让 OS 可移植，初始化片板系
2. **硬件打底**（0203）：选处理器五家之一(MPU/MCU/DSP/GPU/SoC)，冯或哈佛结构，总线连接
3. **开发**（0202）：宿主机交叉编译(目标机装不下编译器)，7 工具链，低功耗 5 方面
4. **跑系统**（0204）：RTOS(微高专实裁)，实时三指标，调度四算法，鸿蒙微内核四层
5. **存数据**（0205）：嵌入式数据库(同进程 API)，三类按存储位置(MMDB 内存/FDB 文件/NDB 网络)

> 一条线：**定义架构 → 硬件处理器 → 开发编译 → 实时 OS → 数据存储**。从"是什么"到"用什么"到"怎么开发"到"跑什么"到"存什么"，搭起一台嵌入式设备。
