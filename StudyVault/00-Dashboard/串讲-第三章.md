# 串讲 · 第三章 计算机网络（9 分）

> 一条线：**网络是什么 → 怎么组 → 跑什么协议 → 怎么设计**。

## 0301 网络技术概述

**网络定义**：通信线路+独立计算机+网络软件协议，实现**资源共享+信息传递**。

**性能指标**：速率/带宽/吞吐量/时延(+利用率)。
- 时延四组成"**发传处排**"（发送/传播/处理/排队）；网络延迟=处理+排队+发送+传播
- 服务器延迟主要因素=**队列延迟+磁盘 I/O 延迟**（真题题眼）

**网络分类**：按范围 LAN/MAN/WAN/Internet。无线四类（**WPAN 802.15 蓝牙 / WLAN 802.11 Wi-Fi / WMAN 802.16 WiMax / WWAN 3G4G**）。局域网**封闭型**。

**拓扑 5 种**：
- 星状：中心结点两步通信，**可靠性低（中心瘫全网瘫）**
- 树状：分级集中式，除叶结点故障影响全网
- 总线：负载有限；环状：首尾单向仅一通路、任一故障瘫
- 网状：任意连接，**可靠性最高**、布线繁成本高
> 可靠性：网状最高、星状最低。

**5G 两特征**：**SBA 服务化架构**（灵活定制+按需组合）/ **网络切片**（一物理网切多逻辑网、故障隔离降成本）。MEC 边缘计算=就近分流（和切片区分）。

**云计算**（官方补肉）：三服务 **SaaS(软件)/PaaS(平台,最关键支撑)/IaaS(设施)**；灵活性 SaaS→PaaS→IaaS 增强（越下越灵活）、方便性 IaaS→PaaS→SaaS 增强（越上越方便）；四部署(NIST)=**公有/社区/私有/混合云**。

## 0302 组网技术

**OSI 设备层次**：物理层(比特)=集线器/中继器；数据链路层(帧)=网桥/交换机/网卡；网络层(IP分组)=路由器/防火墙；传输层(报文段)=TCP/UDP。

**交换机**：基于 MAC 地址。四功能"**学源址、转目的、查不到泛洪、300s 刷新**"。广播组播向所有端口**不含源端口**。STP 解决环路、链路聚合提带宽。
> 交换机=链路层=MAC；路由器=网络层=IP。

**以太网标准**：802.3(10M)/802.3u(100M)/802.3z(1000M)/802.3ae(10G)。WLAN=802.11。**最小帧 64 字节**（避免冲突，按检测冲突最长时间定），最大 1518。

**传输介质**：双绞线(UTP/STP)≤100m，**同类交叉/异类直通**；**多模光纤=LED+短距低成本，单模光纤=LD 激光+远 5km 高成本**。

**通信方式**：单工/半双工/全双工；异步(字符+起停位,效率低) vs 同步(数据块+同步帧,效率高)；串行(远距离) vs 并行(高速内部)。

**三种交换**：
- 电路交换：面向连接，实时高，**利用率低，无差错检测**
- 报文交换：存储转发，无连接，可靠，有延时
- 分组交换：时延小于报文。三分：**数据报**(无连接不可靠,主流) / **虚电路**(面向连接可靠) / **信元交换**(ATM,**53B=5头+48数据**,面向连接可靠)

**网络设备 6 种**：集线器/中继器(物理层)、网桥/交换机(链路层)、路由器/防火墙(网络层)。

## 0303 TCP/IP 协议簇

**TCP/IP 四层**：应用层(=OSI 上三层)/传输层/网际层(网络层,关键)/网络接口层(链路+物理)。

**端口**：**SMTP 25 发邮件 / POP3 110 收 / FTP 20数据21控制 / HTTP 80 / HTTPS 443 / DNS 53 / DHCP 67服务68客户 / Telnet 23**。口诀"25 发、110 收"。

**TCP vs UDP**：
- **TCP**：面向连接、可靠（重发/差错校验/流量控制），少而可靠（FTP/HTTP/SMTP/Telnet）
- **UDP**：无连接、不可靠，多快而糙（DHCP/DNS/TFTP/SNMP）
- **共同=端口寻址**（连接/差错重传/流量控制都 TCP 独有）

**IP 地址分类**：A(0-127,网络号 8 位)/B(128-191,16 位)/C(192-223,24 位)/D 组播(224-239)/E 保留(240-255)。
> 私有：10.x / 172.16-31.x / 192.168.x。特殊：127 环回、169.254 自动专用、0.0.0.0、全 1 广播。
> **网络号位数 A8/B16/C24（类号×8）**。

**子网划分 VLSM**：网络号+子网号+主机号向主机借位。子网掩码与运算判同网段。子网号可全0全1，**主机号不能全0全1（可分配-2）**。
> **/n 看前 n 位做网络号，网络地址相同才同网段**。

**CIDR 无分类**：IP/网络前缀位数（如 /20=网络20主机12）。路由汇聚=子网划分逆过程。**最长前缀匹配**。

**IPv6**：128 位，2^96 倍。过渡三技术：
- **双协议栈**：主机同时运行 IPv4+IPv6 两套栈（并行）
- **隧道技术**：把 IPv6 报文**封装**进 IPv4 数据部分传输（和 VPN 隧道同本质）
- **翻译 NAT-PT**：转换网关**翻译**报头地址+语义
> 口诀：**隧道=封装、翻译=转换、双栈=并行**。

**DHCP**：UDP 67/68，**DORA 四步**（DISCOVER→OFFER→REQUEST→ACK）。Decline 客户端拒 / Nack 服务器拒 / Release 释放。租约 8 天，**50% 续租、87.5% 找其他**。

**DNS**：UDP 53，域名→IP。
- 递归（服务器必须给最终映射）vs 迭代（可给其他 DNS 地址继续查）
- **主机→本地递归、本地→根迭代**，根用递归=影响性能
- **PTR 反向解析**（IP→域名）
- Linux `/etc/resolv.conf` 四关键字：nameserver/domain/search/sortlist

## 0304 网络规划与设计

**冗余设计两目标**：
- **备用路径**：提高**可用性**，**仅主路径失效时启用**（平时闲置）。五考虑=带宽/切换时间/非对称/自动切换/测试
- **负载分担**：提高**性能**，**并行链路同时传递**
> ⚠ 备用路径≠同时使用（同时分担是负载分担）。

**负载分担两特例**：主备**相同**→**负载均衡**；主备**不同**→**策略路由**。

**服务器冗余四方法**：负载均衡器 / NAT / DNS 循环 / 高可用（双机热备：单活一主一备、双活）。

**层次化三层**：
- **核心层**：高端路由交换+冗余高可用，**避免数据包过滤/策略路由**（降时延）
- 汇聚层：策略（安全/流量/路由）
- 接入层：用户接入+管理

**可靠性 vs 可用性**：可靠性=连续无故障运行时间；可用性=可用时间。提高：提可靠性（**软件 Bug 最主要**）+缩短恢复时间。**冗余不是简单叠加**（成本/维护复杂/故障隐患）。

**网络工程三环节**：规划 / 设计（逻辑+物理）/ 实施。

**PDS 综合布线六子系统**：工作区(终端→插座) / 水平布线(插座→楼层配线) / 管理(配线枢纽) / **垂直干线**(楼层↔楼层) / 设备间(机房主配线架) / **建筑群**(楼宇↔楼宇)。
> 垂直干线连**楼层**，建筑群连**楼宇**。

## 串联：网络从搭到用

1. **是什么**（0301）：网络=资源共享+信息传递，指标/分类/拓扑/5G/云定调

> **一条线**：网络是什么（指标/拓扑/5G/云）→ 怎么组（设备/交换机/介质/交换方式）→ 跑什么协议（TCP-UDP/IP/CIDR/DHCP-DNS）→ 怎么设计（冗余/层次化/布线）。
