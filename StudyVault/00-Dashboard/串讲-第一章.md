# 串讲 · 第一章 计算机系统基础知识

> 把计算机从下到上搭起来，7 节就是 7 层。从底层部件到顶层评估，环环相扣。
>
> **一条线：硬件 → OS → 进程 → 内存 → 磁盘 → 文件 → 性能**

---

## ① 硬件底座（0101 计算机系统组成）

冯·诺依曼**五大部件**（运算器+控制器=CPU、存储器、IO），灵魂是"**存储程序**"（程序和数据同等存内存，按地址执行）。指令集两派：**CISC** 复杂（多变长、微程序）、**RISC** 精简（定长单周期、流水线、仅 Load/Store 访存）。CPU 快内存慢→**分级存储**（寄存器>Cache>内存>外存），靠**局部性原理**（循环→时间、顺序→空间）。外设搬运用 **DMA**（主存与外设直传，CPU 不插手）。

→ [[冯诺依曼与指令系统-CISC-RISC]] · [[CPU与局部性原理-分级存储]] · [[IO控制方式]]

## ② OS 管家（0102 操作系统概述）

向上服务应用、向下管硬件，是**软硬件接口**。批处理（无交互吞吐高）、分时（时间片轮转重交互）、实时（重可靠+限时）、分布式（比网络多"**透明性**"）。层次：应用→系统软件→OS→硬件。

→ [[操作系统定义功能层次结构]] · [[操作系统分类]]

## ③ 进程（0103 进程管理）

CPU 调度的活体。进程=程序+PCB+数据，**PCB 是唯一标志**。三态就绪/运行/阻塞，**阻塞→运行不可能**。线程共享进程资源但**栈私有**。PV 管同步互斥（同步初值 0）。前趋图有向无环（有后继 V、有前趋 P）。死锁四条件，最小资源 `n(m−1)+1`，银行家找安全序列避死锁。

→ [[进程线程PCB三态]] · [[同步互斥与PV操作]] · [[前趋图]] · [[死锁与银行家算法]]

## ④ 存储管理=内存管理（0104 存储管理）

页式（等大页、页内碎片）、段式（不等长、外部碎片、共享强）、段页式（先段后页、访存 3 次）。地址变换=页号+页内→查页表→页帧+页内。**快表 TLB** 命中省查表访存。

→ [[页式存储]] · [[段式与段页式存储]]

## ⑤ 磁盘管理=设备层（0105 磁盘管理）

存取=寻道+旋转+传输（**寻道最耗时**）。移臂调度：FCFS / SSTF（近优先但远处饥饿）/ SCAN（双向）/ CSCAN（单向回程不服务）。旋转优化：顺序存放有等待（=周期−处理），间隔分布消除等待。

→ [[磁盘存取时间与旋转优化]] · [[磁盘移臂调度算法]]

## ⑥ 文件系统=文件层（0106 文件系统）

索引节点（直接/一级/二级间接，读盘=间接级+1）。位示图（1bit1块，字数=块数/字长，定位 b/字长 与 b%字长）。Unix=成组链接。**目录崩溃影响最大**。

→ [[索引文件结构]] · [[位示图与空闲空间管理]]

## ⑦ 性能（0107 系统性能）

主频=外频×倍频，MIPS=主频/CPI（**CPI 在分母**），阿姆达尔 `R=1/((1−Fe)+Fe/Se)` 受限不可改进部分（极限 1/(1−Fe)）。5 种评估递进（PDR 首含存储、CTP 最全）。基准（Dhrystone 整数 / Linpack 浮点 TOP500 / TPC 事务）。Web 三指标（并发连接/响应延迟/吞吐量）。

→ [[性能指标MIPS与阿姆达尔定律]] · [[性能评估方法与基准程序]] · [[Web性能评估与系统监视]]

## 跨节统一视角

- **访问次数 = 映射/索引层数 + 1**：段页式访存 3 次、文件二级间接读盘 3 次，同构。inode 在内存不另读盘、快表在 CPU 内不另访存——"不算访存"看结构位置。 → [[Quick-Reference]]
- **缓冲区 = 2 段流水线**：单缓冲读与送串行（每块 max(T,C)+M）、双缓冲读与处理并行（每块 max(T, M+C)）。 → [[Quick-Reference]]
