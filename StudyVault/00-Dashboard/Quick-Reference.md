## 对比速查

**CISC vs RISC** → [[冯诺依曼与指令系统-CISC-RISC]]
| | CISC | RISC |
|---|---|---|
| 指令 | 多、变长 | 少、定长、单周期 |
| 寻址 | 多种 | 少 |
| 实现 | 微程序 | 硬布线、流水线 |
| 访存 | 多指令 | 仅 Load/Store |

**页式 vs 段式 vs 段页式** → [[页式存储]] / [[段式与段页式存储]]
| | 页式 | 段式 | 段页式 |
|---|---|---|---|
| 划分 | 等大小页 | 不等长逻辑段 | 先段后页 |
| 碎片 | 页内（内） | 外部 | 小 |
| 共享保护 | 弱 | 强 | 强 |

**I/O 方式效率递增** → [[IO控制方式]]
查询 → 中断 → DMA → 通道 → I/O 处理机（DMA 在**主存与外设**间直通）

**评价程序精确度** → [[性能评估方法与基准程序]]
真实程序 > 核心程序 > 小型基准程序 > 合成基准程序
