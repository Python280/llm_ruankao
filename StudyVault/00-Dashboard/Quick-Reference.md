## 对比速查

**CISC vs RISC** → [[冯诺依曼与指令系统-CISC-RISC]]
| | CISC | RISC |
|---|---|---|
| 指令 | 多、变长 | 少、定长、单周期 |
| 寻址 | 多种 | 少 |
| 实现 | 微程序 | 硬布线、流水线 |

| | 页式 | 段式 | 段页式 |
|---|---|---|---|
| 划分 | 等大小页 | 不等长逻辑段 | 先段后页 |
| 碎片 | 页内（内） | 外部 | 小 |
| 共享保护 | 弱 | 强 | 强 |

**I/O 方式效率递增** → [[IO控制方式]]
查询 → 中断 → DMA → 通道 → I/O 处理机（DMA 在**主存与外设**间直通）

## 第二章 嵌入式技术

### 对比速查

**冯·诺依曼 vs 哈佛** → [[处理器体系结构与总线]]
| | 冯·诺依曼 | 哈佛 |
|---|---|---|
| 存储 | 指令数据合并 | 分开独立编址 |
| 总线 | 共用 | 4 条（指令/数据各 2） |
| 吞吐 | 瓶颈效应 | 高（并行读） |
| 典型 | PC（i3/i5/i7） | DSP、嵌入式 |

**宏内核 vs 微内核** → [[内核架构与鸿蒙]]
| | 宏内核 | 微内核（鸿蒙） |
|---|---|---|
| 功能位置 | 全在内核 | 服务放内核外 |
| 效率 | 高 | 低（频繁切换） |
| 可靠/安全 | 差 | 高、可剪裁、可分布式 |

**MMDB / FDB / NDB** → [[嵌入式数据库分类与特点]]
| | MMDB | FDB | NDB |
|---|---|---|---|
| 位置 | 内存常驻主拷贝 | 磁盘文件 | 远程映射本地 |
| 特点 | 实时事务最佳 | 被动访问、安全性低 | 无需解析 SQL、客户端小 |

**存取速度**：寄存器组 > Cache > 内存 > Flash → [[嵌入式系统概念与架构]]

- 实时性三指标：**中断、切换、混洗** → [[嵌入式实时操作系统]]
- 调度四算法：**优、抢、早头、晚末**（EDF=最早截止期=头端；最晚=末端）→ [[嵌入式实时操作系统]]
