# 交换技术与组网

> 考情（讲义 p25）：**交换技术约 2 分**。讲义 p4–7 与 p34–37 是同一节"组网技术"的两份拷贝，内容一致，下文页码并记。

## OSI 七层模型：设备与协议（讲义 p4 / p34）

| 层次 | 名称 | 主要功能 | 主要设备及协议 |
|---|---|---|---|
| 7 | 应用层 | 实现具体的应用功能 | POP3、FTP、HTTP、Telnet、SMTP、DHCP、TFTP、SNMP、DNS |
| 6 | 表示层 | 数据的格式与表达、加密、压缩 | — |
| 5 | 会话层 | 建立、管理和终止会话 | — |
| 4 | 传输层 | 端到端的连接 | TCP、UDP |
| 3 | 网络层 | 分组传输和路由选择 | 三层交换机、路由器；ARP、RARP、IP、ICMP、IGMP |
| 2 | 数据链路层 | 传送以帧为单位的信息 | 网桥、交换机（多端口网桥）、网卡；PPTP、L2TP、SLIP、PPP |
| 1 | 物理层 | 二进制传输 | 中继器、集线器（多端口中继器） |

**关键数字：以太网帧最小长度为 64 字节**（讲义 p4 旁注，指向数据链路层）。

**32h 印刷 p22（补充）设备工作层级**：集线器（Hub）和中继器（Repeater）工作在**物理层**；网桥（Bridge）和交换机（Switcher）工作在**数据链路层**；路由器（Router）和防火墙（Firewall）主要工作在**网络层**。

**一本通 p76（补充）各层传输单位**：物理层 = **比特**、数据链路层 = **帧**、网络层 = **IP 分组**、传输层 = **报文段**。

## 交换技术（讲义 p5–6 / p35–36）

### 交换机功能与基本原理（p5 / p35）

数据在网络中转发通常离不开交换机。交换机的功能包括：**集线功能、中继功能、桥接功能、隔离冲突域功能**等。

交换机是一种基于 **MAC 地址**识别、能完成封装转发数据包功能的网络设备。交换机可以"**学习**"MAC 地址，并把其存放在**内部地址表**中，通过在数据的始发者和目标接收者之间建立**临时的交换路径**，使数据直接由源地址到达目的地址。

**32h 印刷 p25（补充）交换机协议**：

- **生成树协议（STP）**：可以很好地解决链路环路问题。
- **链路聚合协议**：提升与邻接交换设备之间的端口带宽，提高链路可靠性。

### 交换机必须实现的四个功能（p6 / p36）

| 功能 | 要点 |
|---|---|
| （1）转发路径学习 | 根据收到数据中的**源 MAC 地址**建立该地址同交换机端口的映射，写入 MAC 地址表 |
| （2）数据转发 | 数据中的**目的 MAC 地址**在 MAC 地址表中查询到了，就向**对应端口**转发 |
| （3）数据泛洪 | 目的 MAC 地址**不在** MAC 地址表中，则向**所有端口**转发（即泛洪）；**广播帧和组播帧**向所有端口（**不包括源端口**）转发 |
| （4）链路地址更新 | MAC 地址表每隔一定时间（如 **300s**）更新一次 |

> [!tip] 记忆口诀
> **学源址、转目的、查不到就泛洪；广播组播全端口、唯独不含源端口；表项 300 秒一刷新。**

## 五种网络拓扑结构（一本通 p75–76 补充）

| 拓扑 | 一本通原文浓缩 |
|---|---|
| 总线型 | 利用率低、干扰大、价格低 |
| 星型 | 交换机形成的局域网、中央单元负荷大 |
| 环型 | 流动方向固定、效率低、扩充难 |
| 树型 | 总线型的扩充、分级结构 |
| 分布式（网状） | 任意节点连接、管理难、成本高 |

办公室局域网是**星型拓扑**，中间节点就是**交换机**——一旦交换机损坏，整个网络都瘫痪；由路由器连接起来的小型网络也是星型结构。

> 注：讲义 p29–31 另有星状/树状/总线/环状四种拓扑 + 网状结构的详细"特点/缺点"对比表，归本章 0301 概述节整理。

## 以太网标准（一本通 p76–77 补充）

| 标准 | 名称 | 速率 | 传输介质 |
|---|---|---|---|
| IEEE 802.3 | 标准以太网 | 10Mb/s | 细同轴电缆 |
| IEEE 802.3u | 快速以太网 | 100Mb/s | 双绞线 |
| IEEE 802.3z | 千兆以太网 | 1000Mb/s | 光纤或双绞线 |
| IEEE 802.3ae | 万兆以太网 | 10Gb/s | 光纤 |

无线局域网 WLAN 技术标准：**IEEE 802.11**。广域网协议：PPP、ISDN、xDSL（HDSL/SDSL/MVL/ADSL）、DDN 数字专线、x.25、FR 帧中继、ATM 异步传输模式。

## 传输介质（一本通 p78–81 补充）

### 双绞线（p78–79）

- 将多根铜线按规则缠绕在一起，能够减少干扰；分为**无屏蔽双绞线 UTP** 和**屏蔽双绞线 STP**，即常说的网线；**传输距离在 100m 以内**。
- UTP 分类：**CAT3**（10Mbps）、CAT4（无应用）、**CAT5**（100Mbps，用于快速以太网）、**CAT5E**（超 5 类，1000Mbps）、**CAT6**（6 类，替代 CAT5E，1000Mbps）。
- STP 比 UTP 多一层**屏蔽层**，可靠性提高，但价格高、安装麻烦，用于对传输可靠性要求很高的场合。
- 两种安装标准 **T568A / T568B**，区别在第 1/2/3/6 四根线的位置；两头同标准 = **直通线**，两头不同标准 = **交叉线**。

| 线缆连接设备情况 | 所采用的线缆种类 |
|---|---|
| 计算机-计算机 | 交叉线 |
| 计算机-交换机 | 直通线 |
| 计算机-路由器 | 交叉线 |
| 交换机-交换机 | 交叉线 |
| 交换机-路由器 | 直通线 |
| 路由器-路由器 | 交叉线 |

> [!tip] 口诀
> **同类设备交叉线，异类设备直通线**（计算机与路由器都算数据端设备，互连用交叉线；交换机是中继设备，与计算机/路由器互连用直通线）。

### 同轴电缆（p80）

分粗、细同轴电缆，传输距离长（几百米）、信号稳定，常用于电视、监视系统、视频信号等；随着数字网络发展已逐步淘汰。

### 光纤（p80–81）

由**纤芯和包层**组成；PC 端出来的是电信号，必须转换为光信号才能经光纤传输（光信号在纤芯中以**全反射**形式传输）。

| 对比项 | 多模光纤 MMF | 单模光纤 SMF |
|---|---|---|
| 纤芯 | 半径较大，可同时传输多种信号 | 半径很小，一般只能传输一种信号 |
| 光源 | **发光二极管 LED** | **激光二极管 LD**（只支持激光信号） |
| 传输形态 | 多条折线全反射，输出脉冲变宽 | 反射角很大，看起来接近一条直线 |
| 成本与适用 | 成本低，效率/可靠性较低，适合**短距离**（100Mbps→2km；1000Mbps→550m） | 成本高，传输距离远（可达 **5km**）、可靠性高 |

### 无线信道（p81）

分为**无线电波**（长波/中波/短波/超短波/微波——地面微波、卫星微波）和**红外光波**（近红外/中红外/远红外）。

## 通信方式与交换方式（一本通 p81–82 补充）

### 通信方向（p81）

- **单工**：数据流只能单向流动（A→B）。
- **半双工**：A、B 可互相通信，但**同一时刻**数据流只能单向流动。
- **全双工**：A、B 在任意时刻都能互相通信。

### 同步方式（p82）

- **异步传输**：每发送一个**字符**，在字符起始和结尾处插入**起始位和停止位**，接收方借此识别；造成资源浪费、传输效率降低。
- **同步传输**：以**数据块**为单位传输；发送前先发一个**同步帧**，接收方做好接收准备后接收数据块，结束后有结束帧确认；一次传一个数据块，**效率高**。

### 串行 vs 并行（p82）

- **串行传输**：只有 1 根数据线，数据 1bit 挨个排队传送，适合**低速设备、远距离**，一般用于广域网。
- **并行传输**：有多根数据线，可同时传输多个 bit，适合**高速设备**，常用于计算机内部各硬件模块之间。

### 三种交换方式（p82）

| 交换方式 | 单位 | 连接性 | 特点 |
|---|---|---|---|
| 电路交换（线路交换） | — | **面向连接** | 建立专用电路；实时性高、**链路利用率低**、**没有差错检测**不可靠；一般用于语音视频通信 |
| 报文交换 | 报文 | 面向无连接 | **存储转发**；收到后先存储并差错校验，无错转发、有错丢弃；有延时但可靠性高 |
| 分组交换 | 分组 | 见下 | 存储转发；分组比报文小，**时延小于报文交换** |

分组交换的三种方式：

- **数据报**：现在主流的交换方式；各分组携带地址信息、自由选择路由路径，接收方按地址重新组装；**面向无连接、不可靠**。
- **虚电路**：先建立一条虚拟通信线路再传输分组，空闲时该线路也可传输其他数据；**面向连接、可靠**。
- **信元交换**：**ATM（异步传输模式）**采用，本质按虚电路方式转发；信元是**固定长度的分组，共 53B = 5B 头部 + 48B 数据域**；面向连接、可靠。

> [!warning] 易错点
> - 交换机按**源 MAC 地址学习**、按**目的 MAC 地址转发**；"读取目的地址添加表项"是错误说法（讲义 p7 题 C 项）。
> - 目的地址查不到表项 → **泛洪**到所有端口，**不是丢弃**；广播/组播帧向所有端口转发但**不含源端口**。
> - MAC 地址表是**动态学习、定期更新**（如 300s），"静态增长"错（讲义 p7 题 D 项）。
> - 以太网帧最小长度 **64 字节**，是为**避免冲突**、按网络中**检测冲突的最长时间**定的（32h 印刷 p22）；最大帧长一般 1518 字节。
> - 双绞线传输距离 **100m 以内**；多模光纤 = LED + 短距离，单模光纤 = LD + 远距离，别记混。
> - 电路交换面向连接但**无差错检测、链路利用率低**；数据报无连接不可靠；虚电路/信元面向连接可靠；**信元 53B（5+48）**。

## 网络设备与 WAN/MAN/WLAN（大纲补漏）

### 六种基本网络设备

| 设备 | 作用 | 工作层次 |
|---|---|---|
| **集线器（Hub）** | 最简单的网络设备；从一个端口收到的数据被**转送到所有其他端口**（不管对端是否准备好）；有一个**上联端口**用于级联扩大网络 | 物理层 |
| **中继器（Repeater）** | 局域网互连设备：**接收并识别网络信号，再生后发送**到其他分支；可连接不同物理介质；要求各分支数据包和逻辑链路协议相同 | 物理层 |
| **网桥（Bridge）** | 包含中继器的功能和特性，可连接多种介质和不同物理分支（以太网、令牌网），将数据包在更大范围内传送；链路层以上信息对它透明 | 数据链路层 |
| **交换机（Switch）** | 为接入的任意两个网络结点提供**独享的转发通路**；具备自动寻址和交换功能，**避免端口冲突、提高网络吞吐量** | 数据链路层 |
| **路由器（Router）** | 在多个网络上交换和路由数据包；通过交换路由信息生成**路由表**（含网络地址、连接信息、路径信息、发送代价）实现路径选择；通常用于**广域网或广域网与局域网的互连** | 网络层 |
| **防火墙（Firewall）** | 网络的**门户**，通过设置安全规则**监视和过滤进出网络的数据**；硬件防火墙把程序做到芯片里，减少 CPU 负担、使路由更稳定 | 主要工作在网络层 |

> [!tip] 来源：官方 §2.5.4 p70–71（物理 p85–86）；工作层次另与 32h 第3小时 印刷p22 口径一致（正文已录）

### 广域网（WAN）

- **特点**：将分布于**更广区域**的计算机设备联接起来的网络，需要使用**路由器和网关设备**；由**通信子网与资源子网**组成。
- **分类**：**公共传输网络、专用传输网络、无线传输网络**三类。
- **相关技术**：同步光网络（**SONET**）、同步数字体系（**SDH**）、数字数据网（**DDN**）、帧中继（**FR**）、异步传输技术（**ATM**）。

> 正文已另录 WAN 协议清单（PPP、ISDN、xDSL、DDN、x.25、FR、ATM），此处补的是大纲要求的"特点、分类"。

### 城域网（MAN）

- 在**单个城市范围**内建立的计算机通信网，采用 **IEEE 802.6** 标准。
- 通常分为 **核心层、汇聚层、接入层**三层。

### 无线局域网（WLAN）

- **标准**：**IEEE 802.11**，有 a、b、g、n、ac 等子标准；**802.11n 传输速率可达 200Mb/s，802.11ac 可达 1Gb/s**。
- **三类拓扑**：

| 拓扑 | 用途/现状 |
|---|---|
| **点对点型** | 用于网络互联和延长 |
| **Hub 型** | 用于终端接入 |
| **完全分布型** | 处于理论探讨阶段，无具体应用 |
