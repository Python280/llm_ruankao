# 嵌入式微处理器分类

## 嵌入式系统发展五阶段（讲义 p11）

| 阶段 | 名称 | 记忆锚点 |
|---|---|---|
| 第一阶段 | 单片微型计算机（SCM）阶段 | 即单片机时代 |
| 第二阶段 | 微控制器（MCU）阶段 | 单片机→控制器 |
| 第三阶段 | 片上系统（SoC） | 系统集成到一片芯片 |
| 第四阶段 | 以 Internet 为基础的嵌入式系统 | 联网化 |
| 第五阶段 | 在智能化、云技术推动下的嵌入式系统 | 智能化 + 云 |

> [!tip] 记忆口诀
> **SCM → MCU → SoC → Internet → 智能云**（单机 → 控制 → 集成 → 联网 → 智能）。

## 嵌入式微处理器五大类（讲义 p12–14）

嵌入式处理器需要根据不同的使用场景选择不同类型的处理器，大致分为 **MPU、MCU、DSP、GPU、SoC**。

### MPU 微处理器（Micro Processor Unit）

- 讲义：将微处理器装配在专门设计的电路板上，**只保留与嵌入式应用有关的母板功能**；一般以某一种微处理内核为核心，每一种衍生产品的处理器内核都是一样的，不同的是**存储器和外设的配置及封装**。
- 一本通 p47（补充）：由通用计算机中的 CPU 演变而来，特征是 **32 位以上**、性能高、价格也较高；与计算机处理器不同，只保留和嵌入式应用紧密相关的功能硬件，去除冗余功能，以最低功耗和资源实现特殊要求；与工业控制计算机相比，**体积小、重量轻、成本低、可靠性高**。常见 **ARM、MIPS、POWER PC**。
- 32h p16（补充）：代表型号 Am186/88、386EX、SC-400、PowerPC、68000、MIPS、ARM 系列等。

### MCU 微控制器（Micro Control Unit，又称单片机）

- 讲义：与 MPU 相比，MCU 的最大优点在于**单片化**，体积大大减小，从而使**功耗和成本下降，可靠性提高**。
- 一本通 p47（补充）：典型代表是单片机，**片上外设资源比较丰富，适合于控制**，是嵌入式系统工业的**主流**；芯片内部集成 ROM/EPROM、RAM、总线、总线逻辑、定时/计数器、看门狗、I/O、串行口、脉宽调制输出、A/D、D/A、Flash RAM、EEPROM 等各种必要功能和外设。
- 32h p16（补充）：包括 8051、P51XA、MCS-251、MCS-96/196/296、C166/167、MC68HC05/11/12/16、68300 和数目众多的 ARM 系列。

### DSP 信号处理器（Digital Signal Processor）

- 讲义：对**系统结构和指令进行了特殊设计**（通常采用一种**哈佛结构**），使其适合于执行 DSP 算法，**编译效率较高，指令执行速度也较高**。
- 一本通 p47（补充）：专门用于信号处理；采用哈佛结构、流水线处理，处理速度**比最快的 CPU 还快 10–50 倍**；数字信号处理的运算特点是**乘/加**（乘积累加），设置了**硬件乘法/累加器**，能在单个指令周期内完成乘法/加法运算；多总线结构，允许 CPU 同时访问指令和数据，可实现流水线操作；在数字滤波、FFT、谱分析等各种仪器上大规模应用。
- 32h p16（补充）：包括 TMS320 系列（C2000、C5000、C6000、C8000）、DSP56000 系列等。

### GPU 图形处理器（Graphics Processing Unit）

- 讲义 p13：可执行 3D 图形渲染等图像的半导体芯片；用于个人电脑、工作站、游戏机和移动设备做图像和图形相关运算；可**减少对 CPU 的依赖**，执行部分原本属于 CPU 的工作，核心技术如**硬件 T&L、纹理压缩**等保证 3D 快速渲染能力；集成了同时运行在 GHz 频率上的**成千上万个 core**，最新的 GPU 峰值性能可高达 **100 TFlops 以上**。
- 32h p16（补充）：与 CPU 相比大幅加强了**浮点运算能力和多核并行计算能力**，因此常用于 AI 技术的深度学习的数据运算。

### SoC 片上系统（System on Chip）（讲义 p14）

- 追求**产品系统最大包容**的集成器件。
- 它是一个**产品**，是一个**有专用目标的集成电路**，其中包含完整系统并有嵌入软件的全部内容。
- 它又是一种**技术**，用以实现从确定系统功能开始，到软/硬件划分，并完成设计的整个过程。
- 成功实现了**软硬件的无缝结合**，直接在微处理器片内嵌入操作系统的代码模块（一本通 p48 原文一致，互为旁证）。
- 减小了系统的体积和功耗、提高了可靠性和设计生产效率。
- **狭义角度**：信息系统核心的芯片集成，是将系统关键部件集成在一块芯片上。
- **广义角度**：SoC 是一个微小型系统——如果说 CPU 是大脑，那么 SoC 就是**包括大脑、心脏、眼睛和手**的系统。
- 学术界定义：将**微处理器、模拟 IP 核、数字 IP 核和存储器（或片外存储控制接口）**集成在单一芯片上，通常是客户定制的，或是面向特定用途的标准产品。

## 其他分类角度（一本通 p47 补充）

- **按字长宽度**：4/8/16/32/64 位；一般把 **16 位及以下**称为嵌入式**微控制器**，**32 位及以上**称为嵌入式**微处理器**。
- **按系统集成度**：一般用途型微处理器（内部仅含单纯的中央处理器单元）／单芯片微控制器（将 CPU、ROM、RAM 及 I/O 等集成到同一个芯片上）。
- **按用途**：嵌入式微控制器 MCU、嵌入式微处理器 MPU、嵌入式数字信号处理器 DSP、嵌入式片上系统 SoC 等。

> [!tip] 记忆口诀
> - **MPU = 板级**（通用核+专门电路板，只留嵌入式相关功能）；**MCU = 单片化**（外设全塞片内，控制主流）；**DSP = 哈佛 + 乘加**（信号处理快）；**GPU = 万核并行**（图形 + AI 算力）；**SoC = 一片全系统**（软硬件无缝结合）。
> - MCU 最大优点四个字：**单片化** → 功耗成本降、可靠性升。

> [!warning] 易错点
> - MCU 与 MPU 对比：MCU 优点是**单片化**（不是性能高）；MPU 才是高性能、高价格（32 位以上）。
> - SoC **不是**单纯的"有运算能力的处理器芯片"，而是**有专用目标的集成电路、包含完整系统**——这是讲义 p15 习题的挖坑点，见 [[练习题-嵌入式硬件]] Q1。
> - DSP 采用**哈佛结构**——与体系结构考点联动，见 [[处理器体系结构与总线]]。
