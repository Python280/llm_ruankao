# 前趋图（Precedence Graph）

## 定义

前趋图是一个**有向无环图**，记为：

$\rightarrow = \{(P_i, P_j) \mid P_i \text{ must complete before } P_j \text{ may start}\}$

- 1 个箭头 = 1 个前趋关系
- A 有箭头指向 D，记为 **(A, D)**（前驱在前）
- 没有前趋的结点 = **起始进程**；没有后继的结点 = **终结进程**

## 用 PV 操作实现前趋图

> [!important] 核心技巧
> - 某活动**有后继** → 执行完后做 **V** 操作（释放资源、通知后继）
> - 某活动**有前趋** → 执行前做 **P** 操作（检查前趋是否完成）
> - **有几个箭头就有几个信号量**；实现并发的信号量初值一般为 **0**

包饺子例子（A 绞肉、B 切葱末、C 切姜末、D 搅拌、E 包饺子；A,B,C→D，D→E）：

```
进程A: 绞肉;   V(Sa)          进程D: P(Sa); P(Sb); P(Sc);
进程B: 切葱末; V(Sb)                 搅拌;   V(Sd)
进程C: 切姜末; V(Sc)          进程E: P(Sd); 包饺子;
```

## 真题核对（已读原图）

**P1–P8 前趋图**（箭头）：P1→P2、P1→P3、P1→P4、P2→P5、P3→P5、P4→P6、P5→P7、P6→P7、P7→P8

```
      ┌→ P2 ─
P1 ───┼→ P3 ─→ P5 ─→ P7 ─→ P8
      └→ P4 ─→ P6 ─
```

集合表示 = {(P1,P2),(P1,P3),(P1,P4),(P2,P5),(P3,P5),(P4,P6),(P5,P7),(P6,P7),(P7,P8)} → **选项 C**

**P1–P4 前趋图**（箭头）：P1→P2、P1→P3、P3→P2、P2→P4、P3→P4（5 个箭头 = 5 个信号量 S1–S5，初值 0）

设 S1: P1→P2，S2: P1→P3，S3: P3→P2，S4: P2→P4，S5: P3→P4：

```
P1: 执行; V(S1)V(S2)      ← a、c 处含 V(S1)V(S2)
P2: P(S1)P(S3); 执行; V(S4)
P3: P(S2); 执行; V(S3)V(S5)
P4: P(S4)P(S5); 执行
```

> [!tip] 填空答案（已核对原图箭头）
> 第一空（a,b,c）= **C**：V(S1)V(S2)、P(S1)P(S3) 和 V(S4)
> 第二空（d,e,f）= **A**：P(S2)、V(S3)V(S5) 和 P(S4)P(S5)

> [!warning] 易错点
> - 前趋关系记为 **(前驱, 后继)**，方向别写反（选项 A/D 常把方向颠倒作干扰）
> - P 操作在"执行前"等前趋，V 操作在"执行后"通知后继
