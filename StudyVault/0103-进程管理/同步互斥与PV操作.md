# 进程的同步与互斥、PV 操作

## 基本概念

- ▲ **临界资源**：诸进程间需要**互斥**方式共享的资源（如打印机）
- **临界区**：进程中访问临界资源的那段代码
- **互斥**：**间接制约**关系——如千军万马过独木桥，一方占用另一方只能等
- **同步**：**直接制约**关系——协作进程因速度差异，在一定情况下停下等待

## 信号量与 PV 操作

信号量 S 是一种特殊变量（只能被 P/V 操作访问的整型量）：
- ✓ S ≥ 0 时表示**可用资源数量**
- ✓ S < 0 时其绝对值表示**排队等待的进程数**

★ P 是荷兰语 **Passeren**（通过/申请），V 是荷兰语 **Verhoog**（增加/释放）。

```
P(S): S = S - 1;  若 S < 0 则阻塞自己入队
V(S): S = S + 1;  若 S ≤ 0 则唤醒一个等待进程
```

> [!important] 初值规则
> - **互斥**信号量初值 = 资源数（如 1 个临界区 → 1）
> - **同步**（实现并发/前趋）信号量初值一般为 **0**
> - 例：2 台打印机、3 个进程互斥使用 → S 初值 **2**，取值范围 **[−1, 2]**（最坏 1 个排队）

> [!tip] PV 成对性
> - 互斥的 PV 在**同一进程内**成对出现（进临界区 P、出 V）
> - 同步的 PV 在**不同进程间**配对（前驱 V 通知、后继 P 等待）

> [!warning] 易错点
> - S = −2 表示**没有可用资源且 2 个进程在排队**
> - P 操作可能阻塞，V 操作**不会**阻塞
> - PV 操作必须是**原语**（执行期间不可中断）

## 经典同步模型（补充）

| 模型 | 信号量设置 |
|---|---|
| 生产者-消费者 | 互斥 mutex=1；空槽 empty=n；产品 full=0 |
| 读者-写者 | 写互斥；读者计数 + 读互斥计数器 |
