# 页式存储管理

## 基本思想

将**程序与内存均划分为同样大小的块**，以**页**为单位将程序调入内存。

- 高级程序语言使用**逻辑地址**；运行状态内存中使用**物理地址**
- **逻辑地址 = 页号 + 页内地址**
- **物理地址 = 页帧号（物理块号）+ 页内地址**（页内地址不变，只换高位）

## 页表

页表实现 页号 → 页帧号 的映射，通常还带三个标志位：

| 位 | 1 表示 | 0 表示 |
|---|---|---|
| 状态位 | 在内存中 | 不在内存中 |
| 访问位 | 最近访问过 | 最近未被访问 |
| 修改位 | 内容被修改过 | 内容未被修改 |

> [!tip] 三个位的用途
> - **状态位**：决定是否需要调页（缺页中断）
> - **访问位**：页面置换时参考（最近没访问的优先淘汰，Clock/LRU 思想）
> - **修改位**：淘汰时参考——未修改的页**无需写回**磁盘，修改过的才写回

## 地址变换示例

页大小 4KB = 2¹² → 页内地址占 **12 位**，高位为页号。

例：逻辑地址 `10 1100 1101 1110`（页号=2，页内=1100 1101 1110），查页表页号 2 → 页帧号 6，则物理地址 = `110 1100 1101 1110`。

> [!important] 真题（已算）
> 页面大小 4K，访问逻辑地址 **5148H**：
> 5148H = 0101 0001 0100 1000 → 页号 = 0101 = 5，页内 = 148H。
> 查页表页号 5 → 页帧号 3 → 物理地址 = **3148H**（选 A）。

## 优缺点

★ 优点：**利用率高、碎片小**（只有页内碎片）、分配及管理简单
★ 缺点：增加了系统开销（查页表、缺页中断）；可能产生**抖动**现象（频繁调页）

> [!warning] 易错点
> - 页式只有**页内碎片**（内部碎片），没有外部碎片；段式相反
> - 页面淘汰的一般原则：优先淘汰**最近未访问（访问位 0）且未修改（修改位 0）**的页（⚠ 讲义原页面变换表数据不全，具体题以原表按此原则判断）
