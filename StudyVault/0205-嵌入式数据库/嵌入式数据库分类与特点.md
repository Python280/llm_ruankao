# 嵌入式数据库分类与特点

## 标准定义与本质

- 名称来自其独特运行模式：数据库**嵌入到应用程序进程中**，消除客户机/服务器配置开销。
- 本质是**轻量级**：运行需较少内存、精简代码、**零配置**运行模式；允许通过 SQL 管理数据而不依赖原始文本文件。
- 对数据库操作有**定时限制**特性 → 称为嵌入式数据库系统或**嵌入式实时数据库系统（ERTDBS）**。
- 要求：**可靠性**（无人干预长时间不间断运行）、**可预知性**（操作/大小/性能可预知）、**底层控制能力**（磁盘操作时机、次数可控）。

> [!important] 嵌入式数据库 vs 数据库服务器（最大区别 = 运行地址空间）
> - 数据库服务器：独立运行一个**守护进程（daemon）**，客户端经 JDBC/ODBC 驱动、走 **TCP/IP** 访问；数据与程序分离。
> - 嵌入式数据库：与应用程序运行在**同一进程**，**不需要驱动程序**，库文件直接链接进应用，经 **API** 访问；与应用程序一起部署，具有**程序携带性**。
> - 典型代表：SQLite、BerkeleyDB（嵌入式）；Oracle、MySQL、SQL Server（服务器）。

## 四特点

| 特点 | 要点 |
|---|---|
| 嵌入式 | **基本特性**；可嵌入其他软件，也可嵌入硬件设备 |
| 实时性 | 与嵌入性分不开；能第一时间获取资源并响应请求；**有嵌入性不一定有实时性**，需额外工作 |
| 移动性 | 与移动设备大规模应用相关；**有嵌入性 → 一定有较好移动性；反之不成立** |
| 伸缩性 | 嵌入式场合软硬件平台千差万别，伸缩性尤为重要 |

> [!tip] 记忆锚点
> 四特点 = 嵌、实、移、伸；两组单向蕴含：**嵌入 ⇒ 移动**、**实时 ⇐ 额外工作（嵌入 ⇏ 实时）**。

## 分类

**按数据库存储位置**分类是目前广泛采用的方法，分为三类：

| 类别 | 全称 | 定义 | 特点（题眼） |
|---|---|---|---|
| MMDB | Main Memory Database System 基于内存 | 实时系统与数据库系统的有机结合 | 支持实时事务的**最佳技术**；本质特征：**"主拷贝"/"工作版本"常驻内存**，活动事务只与内存拷贝打交道 |
| FDB | File Database 基于文件 | 以文件方式存储数据（按格式存磁盘），应用经驱动程序甚至直接读写数据文件 | 访问方式**被动式**；了解格式任何程序都可直接读 → **安全性很低**；仍可满足嵌入式空间/时间特殊要求 |
| NDB | Netware Database 基于网络 | 基于手机 4G/5G 移动通信，逻辑上嵌入式设备 = 远程服务器的一个客户端 | **无需解析 SQL 语句**；支持更多 SQL 操作；**客户端小、无须支持可剪裁性**；有利于代码重用 |

其他分类方法（了解）：按嵌入对象 → 软件嵌入/设备嵌入/内存数据库；按系统结构 → 嵌入数据库/移动数据库/小型 C/S 结构数据库。

> [!tip] MMDB 为什么支持实时事务（官方补肉）
> 磁盘数据库因磁盘存取、内外存传递、缓冲区管理、排队等待、锁延迟，实际执行时间与最坏估算相差大；MMDB 让事务执行中**不访问 I/O**，可精确估算/安排处理时间 → 支持**动态预测性**、为事务**定时限制**打基础。应用：航空、军事、电信、电力、工业控制；**分布式内存数据库**是新研究热点。

> [!tip] FDB 实例
> DBF、Access、Paradox 是文件型数据库；嵌入式 **PocketAccess** 也是文件型。

## NDB 三组成与综合信息系统

- **实质**：把功能强大的远程数据库**映射到本地数据库**，访问远程如同访问本地。
- **三组成**：
  1. **客户端** —— 提供接口给嵌入式程序；
  2. **通信协议** —— 规范客户端与远程服务器间通信，并解决**多客户端并发**问题；
  3. **远程服务器** —— 维护服务器上的数据库数据。
- 综合信息系统 = 嵌入式网络数据库 + 嵌入式本地数据库（内存或文件）+ 嵌入式 Web 服务器。

## 一般架构与主要功能

**主要功能四点**：足够高效的**数据存储机制**；**数据安全控制（锁机制）**；**实时事务管理机制**；**数据库恢复机制（历史数据存储）**。

功能模块划分：运行处理 / 存取 / 管理 / 维护 / 定义。五个需特别解决的设计问题：存储空间管理、安全性与完整性控制、**事务并发控制（封锁粒度常取一张关系表为单位）**、实时数据转储、运行日志管理。

**典型产品**：SQLite（3.3.8 版 DLL 仅 374KB、ACID、最大 2TB）、BerkeleyDB（可管理 256TB、高并发）、Firebird 嵌入服务器版（零成本迁移、支持 SQL-92）、eXtremeDB（内存式、实时性强）。
