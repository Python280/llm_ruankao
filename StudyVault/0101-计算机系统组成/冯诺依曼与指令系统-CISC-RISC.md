# 冯·诺依曼计算机组成与指令系统

## 冯·诺依曼体系结构

核心思想：**存储程序**——程序和数据以同等地位存放于存储器，按地址顺序执行，遇到跳转/中断才改变顺序。

五大部件：

```
┌──────────┬──────────┬────────┬──────────┬──────────┐
│  运算器  │  控制器  │ 存储器 │ 输入设备 │ 输出设备 │
└──────────┴──────────┴────────┴──────────┴──────────┘
     ▲ CPU = 运算器 + 控制器
```

> [!important] 存储程序原理
> 程序和数据同等存于存储器；指令按地址顺序执行；这是冯·诺依曼机区别于早期人工接线的根本特征。

## 计算机系统组成（层次）

- **硬件**：CPU（运算器+控制器）、存储器、I/O 设备、总线
- **软件**：系统软件（OS、编译器、DBMS、中间件）、应用软件

## 指令系统：CISC vs RISC

| 对比项 | CISC（复杂指令集） | RISC（精简指令集） |
|---|---|---|
| 指令数量 | 多，使用频率差别大 | 少，使用频率接近 |
| 指令格式 | 可变长格式 | 定长格式 |
| 寻址方式 | 支持多种 | 支持方式少 |
| 实现方式 | 微程序控制（微码） | 硬布线逻辑为主；适合流水线 |
| 访存 | 多种指令操作内存 | 只有 Load/Store 操作内存 |
| 寄存器 | — | 增加通用寄存器，减少访存 |
| 周期 | — | 大部分为单周期指令 |
| 编译/周期 | 研制周期长 | 优化编译，有效支持高级语言 |
| 代表 | Intel、AMD 的 x86 CPU | ARM、Power |

> [!tip] 记忆口诀
> - **CISC** = "C"复杂 = 指令多、格式变、微程序、周期长
> - **RISC** = "R"精简 = 指令少、定长、硬布线、流水线、寄存器多、单周期
> - 只有 RISC 的 Load/Store 才访存——高频考点

> [!warning] 易错点
> "寻址方式尽量丰富、指令功能尽可能强"是 **CISC** 特点，不是 RISC。问"RISC 特点不包括"的就选它。
