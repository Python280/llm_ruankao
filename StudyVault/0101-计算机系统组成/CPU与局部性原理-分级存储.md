# CPU、局部性原理与分级存储体系

## 中央处理器 CPU

CPU = 运算器 + 控制器，主要功能：
- **程序控制**：执行指令、控制执行顺序
- **操作控制**：产生控制信号
- **时间控制**：时序协调
- **数据加工**：算逻运算

## 局部性原理（程序局部性）

程序执行时对存储器的访问倾向于集中在较小范围内。

| 类型 | 定义 | 典型原因 |
|---|---|---|
| 时间局部性 | 某指令一旦执行，不久后可能再次执行 | 程序中存在大量循环 |
| 空间局部性 | 访问某存储单元后，其附近单元也将被访问 | 程序顺序执行 |

例：双重循环 `for(i...)for(j...)`——内层循环体被反复执行体现**时间局部性**；数组顺序访问体现**空间局部性**。

> [!important] 局部性是分级存储体系的理论基础
> 因为访问集中，所以可以把"近期要用"的热点数据放最快的层（Cache），整体性能接近最快的层、容量接近最慢的层。

## 分级存储体系

```
速度↑  寄存器（最快，最小，最贵）
  │     Cache（L1/L2/L3）
  │     主存（内存）
  │     辅存（磁盘/SSD）
速度↓  海量存储（最慢，最大，最便宜）
```

> [!tip] 为什么要分级？
> 解决**存储的容量、价格、速度之间的矛盾**——单一存储器无法同时做到大容量、低成本、高速度。
> ⚠ "分级存储主要目的"题答案就是"解决容量、价格、速度的矛盾"，不是"主存容量不足"。

## Cache 基本原理

- 依据局部性原理设置
- **命中**：CPU 直接从 Cache 取数据
- **未命中**：从主存取，同时装入 Cache
- 命中率 = 命中次数 / 访问总次数
- **平均访问时间 = 命中率 × Cache 时间 + (1−命中率) × 主存时间**
