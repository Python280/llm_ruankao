# I/O 控制方式

外设与主机之间数据输入输出的控制方式，效率由低到高：

| 方式 | 原理 | CPU 利用率 | 关键特征 |
|---|---|---|---|
| 程序控制（查询） | CPU 轮询外设状态 | 低（CPU 等待） | 无条件传送 / 程序查询；简单、硬件开销小 |
| 程序中断 | 外设准备好发中断，CPU 响应 | 较高 | CPU 无需等待；CPU 与 I/O 可并行 |
| DMA | 主存与外设间直接批量数据交换 | 高 | CPU 与 I/O 传输可并行；周期窃取 |
| 通道方式 | 通道有自己的指令，独立管理 I/O | 更高 | 通道程序，主机只管启动/结束 |
| I/O 处理机 | 专用处理机，功能最强 | 最高 | — |

> [!important] 效率递进记忆
> 查询 → 中断 → DMA → 通道 → I/O 处理机，**效率越来越高**，CPU 介入越来越少，CPU 与 I/O 并行度越来越高。

> [!tip] DMA 高频考点
> - DMA 在 **主存与外设** 之间建立直接数据通路（不经 CPU）
> - 用于**高速、批量**数据交换
> - 比程序控制和中断方式都高效
> - ⚠ DMA 传送期间 CPU 仍可执行（周期窃取占用总线但不全程占用 CPU）

> [!warning] 易错点
> "DMA 直接数据通路在（）之间" → 答 **主存与外设**，不是 CPU 与外设、不是 CPU 与主存。
