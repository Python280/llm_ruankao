# 企业信息化与战略规划

> 本节覆盖讲义 p24-33：信息化概念/要素/目的/需求三层次、六种信息化方法、信息系统战略规划方法（CSF/SST/BSP 三方法对比）。配套练习见 [[练习题-企业信息化与电子商务]]。

## 信息化的概念与要素

**信息化定义**（讲义逐字）：信息化是指在**国家宏观信息政策指导下**，通过**信息技术开发、信息产业的发展、信息人才的配置**，最大限度地利用信息资源以满足全社会的信息需求，从而加速社会各个领域的共同发展以推进信息社会的过程。

**信息化四要素**（判断题逐字抠）：

| 要素 | 内容 |
|---|---|
| 主体 | **全体社会成员**（政府、企业、团体和个人） |
| 时域 | 一个**长期过程** |
| 空域 | 经济和**社会的一切领域** |
| 手段 | **先进社会生产工具** |

**企业信息化定义**（官方教程表述，比讲义更常作判断/选择题干）：企业信息化就是企业利用现代信息技术，通过信息资源的深入开发和广泛利用，实现企业**生产过程的自动化、管理方式的网络化、决策支持的智能化和商务运营的电子化**，不断提高生产、经营、管理、决策的效率和水平，进而提高企业经济效益和企业竞争力的过程。

- 动态视角：信息技术**由局部到全局、由战术层次到战略层次**向企业全面渗透
- 核心和本质：企业运用信息技术，进行**知识的挖掘和编码**，对**业务流程进行管理**
- 实施两方向：**自上而下**须与制度创新、组织创新、管理创新结合；**自下而上**须以业务人员的直接受益和使用水平逐步提高为基础

> [!tip] 来源
> 讲义 p24；官方教程 §3.8.2（印刷 p143）。

## 企业信息化的目的与三类创新

**目的**：具体目标是**优化企业业务活动使之更加有效**；根本目的在于**提高企业竞争能力**，使企业具有平稳和有效的运作能力，对紧急情况和机会做出快速反应，为企业内外部用户提供有价值的信息。

**涉及三类创新**（考点：给出做法反推属于哪类创新）：

| 创新 | 要点 |
|---|---|
| **技术创新** | 生产工艺设计、产品设计中使用**计算机辅助设计系统**；通过互联网及时掌握创新技术信息，加快**技术向生产的转化**；生产技术与信息技术结合，提高技术水平和产品竞争力 |
| **管理创新** | 对现有**管理流程重新整合**：从管理核心的**财务、资金管理**，转向技术、物资、人力资源管理，延伸到技术创新、工艺设计、产品设计、生产制造过程管理，进而扩展到**客户关系管理、供应链管理乃至电子商务** |
| **制度创新** | 不适应企业信息化的**管理体制、管理机制和管理制度**必须得到创新 |

> [!tip] 来源
> 讲义 p25；官方教程 §3.8.2（印刷 p143-144）。

## 信息化需求的 3 个层次

组织对信息化的需求是**组织信息化的原动力**。三个层次（自上而下，考点是"目标/内容→层次"反推）：

| 层次 | 目标/包含内容 |
|---|---|
| **战略需求** | 目标是**提升组织的竞争能力**，为组织的可持续发展提供支持环境 |
| **运作需求** | 包含三方面：①实现信息化战略目标的需要；②**运作策略**的需要；③**人才培养**的需要 |
| **技术需求** | 在信息技术层面上对系统的**完善、升级、集成和整合**提出的需求 |

> [!tip] 来源
> 讲义 p26-27（含 p27 习题，见 [[练习题-企业信息化与电子商务]] Q3）。

## 企业信息化的规划（官方补充）

企业信息化一定要建立在**企业战略规划基础之上**；企业信息化就是**技术和业务的融合**，这个"融合"不是简单地把信息系统对手工流程做自动化改造，而要从 **3 个层面**实现：

| 层面 | 要点 |
|---|---|
| **企业战略层面** | 分析业务策略与发展方向，找出实现战略目标的**关键要素**及其与信息技术的潜在关系，确定信息技术应用的**驱动因素**，达到战略融合 |
| **业务运作层面** | 找出关键驱动力与**关键流程**（按对价值贡献程度确定）；信息系统与直接创造价值的关键流程融合，是信息化投资回报的关键，也是**信息化建设成败的衡量指标** |
| **管理运作层面** | 属辅助流程但关乎日常管理的科学性、高效性；除应用功能需求外还须给出相应的**信息技术体系** |

**企业战略数据模型**分两种：**数据库模型**（描述日常事务处理中数据及其关系，是基础）与**数据仓库模型**（描述企业高层管理决策者所需信息及其关系）。

> [!tip] 来源
> 官方教程 §3.8.2（印刷 p144）。讲义未单列，补肉来源标注于此。

## 企业信息化方法（六种）

| 方法 | 题眼（切入点/中心思想） |
|---|---|
| **业务流程重构方法** | 对企业的组织结构和工作方法进行"**彻底的、根本性的**"重新设计（对应 BPR） |
| **核心业务应用方法** | **围绕核心业务**推动信息化（如石油企业的勘探开发生产） |
| **信息系统建设方法** | 建设信息系统是企业信息化的**重点和关键**，最具普遍意义 |
| **主题数据库方法** | 建立**面向企业核心业务**的数据库，消除"**信息孤岛**"；适合业务浩繁、流程复杂的大型企业，投入少、效益好 |
| **资源管理方法** | 切入点是为企业**资源管理**提供强大能力，如 **ERP、SCM** |
| **人力资本投资方法** | 人力资本理论**把一部分企业的优秀员工看作是一种资本**，能取得投资收益；适合依靠**智力和知识**生存的企业（咨询、软件开发）。注意：**不是"人力资源管理"** |

> [!warning] 易混点
> ①"人力资本"≠"人力资源"，题干出现"优秀员工是资本、投资收益"→ 人力资本投资方法；②"消除信息孤岛"在主题数据库方法与 EAI（[[综合信息系统与电子商务]]）中都会出现，注意题干问的是"信息化方法"还是"集成技术"。

> [!tip] 来源
> 讲义 p28；官方教程 §3.8.2（印刷 p144-145）。

## 信息系统战略规划方法总览（三阶段发展）

| 阶段 | 特征 | 代表方法 |
|---|---|---|
| 第一阶段 | 以**数据处理**为核心、围绕**职能部门**需求 | **关键成功因素法 CSF、战略集合转化法 SST、企业系统规划法 BSP**；另有投资回收法、征费法、零线预算法、阶石法 |
| 第二阶段 | 以**企业内部 MIS** 为核心、围绕**企业整体**需求 | **战略数据规划法 SDP**：主题数据库、信息工程法 IE、战略栅格法 SG |
| 第三阶段 | 综合考虑企业内外环境、以**集成**为核心、围绕**企业战略**需求 | **价值链分析法 VCA、战略一致性模型 SAM** |

缩写全称备查：CSF = Critical Success Factors；SST = Strategy Set Transformation；BSP = Business System Planning；SDP = Strategic Data Planning；IE = Information Engineering；SG = Strategic Grid；VCA = Value Chain Analysis；SAM = Strategic Alignment Model。

> [!tip] 来源
> 讲义 p29（三阶段对应图）。

## CSF / SST / BSP 三方法对比（高频）

| 方法 | 核心思想 | 一句话题眼 |
|---|---|---|
| **CSF 关键成功因素法** | 从企业战略目标出发，分析企业战略中的**关键信息集合**，确定开发**优先次序** | **能抓住主要矛盾** |
| **SST 战略集合转化法** | 把整个过程看成一个"**信息集合**"，将组织的**战略目标**（使命、目标、战略）转变为**管理信息系统的战略目标** | 战略"转化" |
| **BSP 企业系统规划法** | **自上而下**地识别企业目标、企业过程和数据，然后对数据进行分析，**自下而上**地设计信息系统；用 **UC 矩阵**划分子系统 | **自上而下规划、自下而上实现** |

**BSP 的 UC 矩阵**（用于**子系统划分**）：U = Use（使用），C = Create（创建）。行是过程/功能，列是数据类，通过 C/U 分布划分子系统。讲义示例（在线考试系统）：

| 过程 \ 数据 | 学员信息 | 试卷 |
|---|---|---|
| 注册 | C | |
| 权限判断 | U | |
| 添加试卷 | | C |
| 在线测试 | U | U |

> [!tip] 来源
> 讲义 p30-32（三张示意图 + UC 矩阵表）；p33 习题见 [[练习题-企业信息化与电子商务]] Q1。

> [!summary]- 本节题眼
> ①信息化四要素：主体=全体社会成员、时域=长期、空域=经济社会一切领域、手段=先进生产工具；②三类创新：技术（CAD/转化）/管理（流程重整合→财务转向）/制度（体制创新）；③需求三层次：战略（竞争力）/运作（目标+策略+人才）/技术（完善升级集成）；④六方法口诀"**流核系主资人**"；⑤规划三阶段：部门（CSF/SST/BSP）→整体（SDP/IE/SG）→战略（VCA/SAM）；⑥CSF 抓主要矛盾、SST 战略转化、BSP 自上而下规划自下而上实现 + UC 矩阵。
