## p025

（页眉标题：状态图）

状态图（state diagram）是对类描述的补充。用于展现此类对象所具有的可能状态，以及某些事件发生时其状态转移情况。

[图] 烧水壶状态图：

| 源状态 | 触发事件[监护条件]/动作 | 目标状态 |
| --- | --- | --- |
| （初始状态，实心圆点） | — | Off |
| Off | turnOn[没水] | Off（自环） |
| Off | turnOn[有水]/烧水 | On |
| On | 水开了/turnOff | Off |
| On | 烧坏 | （终态，同心圆） |

[图] 转换结构标注图：以 Off 到 On 的转换"turnOn[有水]/烧水"为例，标注各组成部分：源状态（Off）、触发事件（turnOn）、监护条件（有水）、动作（烧水）、转换（箭头本身）、目标状态（On）。

## p028

（页眉标题：活动图）

活动图（activity diagram）是一种特殊的状态图。活动图描述一个操作中要进行的各项活动的执行流程。同时，也常被用来描述一个用例的处理流程或者某种交互流程。

活动图将进程或其他计算结构展示为计算内部一步步的控制流和数据流。它强调对象间的控制流程。

[图] 订单活动图：

- 初始状态→用户下订单→分叉条（水平粗线，并行分支）
- 分支1：生成送货单
- 分支2：用户选择支付方式→判断"用户取消或订单超过时限"：[Yes]→终态（订单取消）；[No]→收款
- 生成送货单、收款汇合于汇合条（水平粗线）→供应商送货→修改订单项状态→判断"所有订单项已送货完毕"：[No]→返回供应商送货；[Yes]→终态（订单完成）

## p031

（页眉标题：定时图）

定时图也叫计时图，也是一种交互图，用于展示交互过程中的真实时间信息，具体描述对象状态变化的时间点以及维持特定状态的时间段。

[图] "标准洗"定时图：纵轴为状态层级（自下而上）：浸泡、洗涤、脱水、漂洗；横轴时间刻度：0、10、30、35、50、55、70、75；图中"状态"箭头指向某一状态层级段，"状态改变"箭头指向层级跳变的边沿。

| 时间段 | 状态 |
| --- | --- |
| 0–10 | 浸泡 |
| 10–30 | 洗涤 |
| 30–35 | 脱水 |
| 35–50 | 漂洗 |
| 50–55 | 脱水 |
| 55–70 | 漂洗 |
| 70–75 | 脱水 |

## p032

（页眉标题：构件图与包图）

构件图（component diagram）。构件图描述一个封装的类和它的接口、端口，以及由内嵌的构件和连接件构成的内部结构。构件图用于表示系统的静态设计实现视图。对于由小的部件构建大的系统来说，构件图是很重要的。构件图是类图的变体。

[图] 构件图示例（机房收费系统），虚线箭头表示依赖关系：

| 依赖方 | 被依赖方 |
| --- | --- |
| 机房收费系统.exe | 机房收费系统源代码 |
| 机房收费系统源代码 | 报表 |
| 机房收费系统源代码 | 选项卡 |
| 机房收费系统源代码 | 窗体 |
| 机房收费系统源代码 | 表格 |
| 报表 | gregn50.dll |
| 选项卡 | tabctl32.dll |
| 窗体 | mscomct2.ocx |
| 表格 | mshflexgd.dll |

包图，包的图标像是一个带标签的文件夹，包的基本思想是把共同工作的元素放到一个文件夹中。例：多个类或构件组成了一个子系统，就可以将它们放到一个包中。
