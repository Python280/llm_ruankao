## p019

标题：类图与对象图

类图（class diagram）：类图描述一组类、接口、协作和它们之间的关系。

对象图（object diagram）：对象图描述一组对象及它们之间的关系。对象图描述了在类图中所建立的事物实例的静态快照。

读图要点：
- 类名，方法名，属性名
- 多重度
- 关系

[图] 类图示例（书籍借阅）：

| 类 | 属性 | 方法 |
|---|---|---|
| 书籍列表 | — | 新增()、修改()、查询()、统计() |
| 书籍 | 书号、书名、类别、作者、出版社、定价 | — |
| 借阅记录列表 | — | 打印() |
| 借阅记录 | 书号、借阅人、借阅时间 | — |
| 非计算机类书籍 | （空） | （空） |
| 计算机类书籍 | （空） | （空） |

图中关系：
- 书籍列表 ◇—— 书籍：多重度 1 对 0..*（聚合，空心菱形在书籍列表端）。
- 借阅记录列表 ◇—— 借阅记录：多重度 1 对 0..*（聚合）。
- 书籍 —— 借阅记录：多重度 1 对 0..1（关联）。
- 非计算机类书籍 ——▷ 书籍（泛化，空心三角指向书籍）。
- 计算机类书籍 ——▷ 书籍（泛化）。

## p020

标题：类图与对象图（多重度含义）

| 多重度 | 含义 |
|---|---|
| 1 | 表示一个集合中的一个对象对应另一个集合中一个对象。 |
| 0..* | 表示一个集合中的一个对象对应另一个集合中的0个或多个对象。（可以不对应） |
| 1..* | 表示一个集合中的一个对象对应另一个集合中的一个或多个对象。（至少对应一个） |
| * | 表示一个集合中的一个对象对应另一个集合中的多个的对象。 |

## p021

标题：类图与对象图（类图关系）

- 依赖关系：一个事物发生变化影响另一个事物。
- 泛化关系：特殊/一般关系。
- 关联关系：描述了一组链，链是对象之间的连接。
  - 聚合关系：整体与部分生命周期不同。
  - 组合关系：整体与部分生命周期相同。
- 实现关系：接口与类之间的关系。

[图] UML 线型图例：

| 关系 | 线型 |
|---|---|
| 依赖关系 | 虚线 + 实心箭头 |
| 泛化关系 | 实线 + 空心三角箭头 |
| 组合关系 | 实线 + 实心菱形 |
| 聚合关系 | 实线 + 空心菱形 |
| 实现关系 | 虚线 + 空心三角箭头 |

[图] 关系示例（六个小图）：
- (a) 关联关系：类A ——— 类B（实线连接）。
- (b) 依赖关系：类A ┄┄▶ 类B（虚线实心箭头）。
- (c) 泛化关系：子类 ———▷ 父类（实线空心三角指向父类）。
- (d) 聚合关系：部分类 ——◇ 整体类（空心菱形在整体类端）。
- (e) 组合关系：部分类 ——◆ 整体类（实心菱形在整体类端）。
- (f) 实现关系：类A ┄┄▷ 类B（虚线空心三角指向类B）。

顺序图（sequence diagram，序列图）。顺序图是一种交互图（interaction diagram），它强调对象之间消息发送的顺序，同时显示对象之间的交互。

[图] ATM 会话顺序图示例：

参与者/对象：:CardReader、:ATM、:CustomerConsole、:Session（由消息2创建）、:Transaction（在 loop 片段内创建）。

消息序列：
1: cardInserted()（:CardReader → :ATM，同步消息）
2: create(this)（:ATM → :Session，参与者创建消息）
3: performSession()（:ATM → :Session）
4: readCard()（:Session → :CardReader，异步消息）
5: card（:CardReader → :Session，返回消息）
6: readPIN()（:Session → :CustomerConsole，简单消息）
7: PIN（:CustomerConsole → :Session，返回消息）
loop 序列片段：while customer wants to perform transaction
　8:（:Session → :Transaction，图中未标消息文本）
　9:（→ :Transaction 激活期，图中未标消息文本）
　10: doAgain（:Transaction ┄┄返回 :Session）
　:Transaction 生命线末端 X（生命结束）
11: ejectCard()（:Session → :CardReader）
:Session 生命线末端 X（参与者销毁消息）
